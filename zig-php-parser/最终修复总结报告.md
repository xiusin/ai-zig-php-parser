## 📝 技术要点总结

### 1. Zig 0.15.2 关键变化

#### ArrayList API
```zig
// 旧版本
var list = std.ArrayList(u8).init(allocator);
defer list.deinit();

// 新版本
var list = std.ArrayList(u8){};  // 空初始化
defer list.deinit(allocator);     // 需要 allocator
```

#### 模块系统
```zig
// 不推荐（会有警告）
const types = @import("../runtime/types.zig");

// 推荐
const runtime = @import("runtime");
const types = runtime.types;
```

### 2. 模块结构最佳实践

#### 创建模块入口文件
```zig
// src/runtime/mod.zig
pub const types = @import("types.zig");
pub const vm = @import("vm.zig");
pub const func = @import("func.zig");

// 导出常用类型
pub const Value = types.Value;
pub const PHPString = types.PHPString;
```

#### 在 build.zig 中定义模块
```zig
const runtime_mod = b.createModule(.{
    .root_source_file = b.path("src/runtime/mod.zig"),
});

exe.root_module.addImport("runtime", runtime_mod);
```

### 3. 并发安全模式

#### 原子操作
```zig
access_count: std.atomic.Value(u64),

// 使用
_ = self.access_count.fetchAdd(1, .monotonic);
const count = self.access_count.load(.monotonic);
```

#### 互斥锁保护
```zig
pub fn get(self: *PHPSharedData, key: []const u8) ?[]const u8 {
    self.mutex.lock();
    defer self.mutex.unlock();
    return self.data.get(key);
}
```

### 4. 错误处理模式

#### 错误联合类型
```zig
// !T - 可能返回错误的类型
pub fn recv(self: *Channel) !Value { ... }

// !?T - 可能返回错误或 null 的类型
pub fn recv(self: *PHPChannel) !?Value { ... }
```

#### 错误转换
```zig
pub fn recv(self: *PHPChannel) !?Value {
    const value = self.channel.recv() catch |err| {
        if (err == error.ChannelClosed) return null;
        return err;
    };
    return value;
}
```
