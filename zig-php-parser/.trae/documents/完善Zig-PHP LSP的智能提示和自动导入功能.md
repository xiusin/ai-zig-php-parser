## 实现计划

### 1. 增强LSP服务器的完成支持
- **添加`textDocument/completion`请求处理**：支持编辑器的自动完成功能
- **实现`CompletionItem`类型**：定义LSP完成项的数据结构
- **添加`CompletionList`类型**：用于返回完成结果

### 2. 多语法关键词提醒
- **为每种语法模式添加关键词列表**：在`syntax_mode.zig`中为PHP和Go模式添加关键词
- **实现语法感知的完成逻辑**：根据当前文档的语法模式提供相应的关键词
- **支持混合模式**：根据文件不同部分的语法模式提供不同的关键词

### 3. 内置库语法提醒
- **创建内置符号注册表**：在`compiler/root.zig`中添加内置函数、类和常量的注册表
- **按类别组织内置符号**：函数、类、常量、命名空间等
- **实现内置符号的完成支持**：根据上下文提供相关的内置符号

### 4. 自动导入功能
- **实现符号解析**：检测未定义的符号并查找可能的导入来源
- **添加导入建议**：为未定义的符号提供可能的导入路径
- **生成导入语句**：根据当前语法模式生成正确的导入语句
- **实现`textDocument/codeAction`支持**：提供自动导入的代码操作

### 5. 代码修改点

#### `tool/lsp/main.zig`
- 添加LSP完成相关类型定义
- 实现`textDocument/completion`处理器
- 实现`textDocument/codeAction`处理器
- 添加符号解析和导入建议逻辑

#### `src/compiler/root.zig`
- 添加内置符号注册表
- 实现符号查找和匹配函数

#### `src/compiler/syntax_mode.zig`
- 为每种语法模式添加关键词列表
- 实现关键词查找函数

### 6. 技术实现要点
- **语法感知**：根据当前文档的语法模式提供相应的建议
- **上下文感知**：根据当前位置的语法上下文提供相关建议
- **高效匹配**：使用哈希表或前缀树实现快速符号匹配
- **内存安全**：确保所有动态分配的内存都被正确释放
- **无侵入性**：不修改核心编译逻辑，只扩展LSP功能

### 7. 测试要点
- 测试不同语法模式下的关键词提醒
- 测试内置库函数和类的提醒
- 测试自动导入功能
- 测试混合模式下的智能提示

## 预期效果

1. **关键词提醒**：根据当前语法模式自动提供相关关键词
2. **内置库提醒**：智能提示PHP内置函数、类和常量
3. **自动导入**：为未定义的符号提供自动导入建议
4. **多语法支持**：同时支持PHP和Go语法模式的智能提示

这个计划将使Zig-PHP LSP具备现代化编辑器的核心智能提示功能，提升开发体验。
