## 🚨 最关键的问题

### 1. GC 实现分裂（严重）

**问题**：
- vm.zig 有简化的 GC 实现（不完整，有内存安全风险）
- complete_gc.zig 有完整的 GC 实现（未使用）
- 两套代码并存，造成混乱和维护困难

**影响**：
- ⚠️ 可能导致活对象被错误回收（UAF）
- ⚠️ 内存碎片无法整理
- ⚠️ 代码重复，维护困难

**修复方案**：
```zig
// 1. 修改 vm.zig 使用 CompleteGC
const CompleteGC = @import("../runtime/complete_gc.zig").CompleteGC;

pub const BytecodeVM = struct {
    gc: CompleteGC,  // 使用完整的 GC
    // 移除简化的 GC 字段
};

// 2. 移除 vm.zig 中的简化 GC 代码
// - markPhase (简化版本)
// - sweepPhase (简化版本)
// - compactPhase (打桩版本)
```

**优先级**：🔴 P0 - 必须立即修复

---

### 2. 内存安全风险（严重）

**发现的风险**：

| 风险类型 | 位置 | CWE | 严重程度 |
|---------|------|-----|---------|
| UAF | vm.zig GC 标记 | CWE-416 | 🔴 严重 |
| 双重释放 | vm.zig free_strings | CWE-415 | 🔴 严重 |
| 悬垂指针 | vm.zig 字符串池 | CWE-476 | 🟡 高 |
| 数据竞争 | vm.zig 类型反馈 | CWE-362 | 🟡 高 |

**修复方案**：
1. 使用 complete_gc.zig（解决 UAF）
2. 添加 magic_number 防护（解决双重释放）
3. 释放后清零指针（解决悬垂指针）
4. 添加互斥锁保护（解决数据竞争）

**优先级**：🔴 P0 - 必须立即修复

**优点**：

- ✅ 测试覆盖 100%
- ✅ 代码结构清晰
- ✅ 文档完善

**代码示例**：
```zig
pub const TypeInference = struct {
    allocator: std.mem.Allocator,
    type_profiles: std.StringHashMap(TypeProfile),
    inference_rules: []const InferenceRule,
    
    // 完整的推断逻辑
    pub fn inferType(self: *TypeInference, var_name: []const u8) TypeInfo {
        // 检查推断规则
        for (self.inference_rules) |rule| {
            if (rule.isSatisfied(&profile)) {
                return profile.getMostLikelyType();
            }
        }
        return .dynamic;
    }
};
```

### 步骤 2：添加内存安全防护

```zig
// 添加 magic_number 防护
pub const String = struct {
    data: []u8,
    ref_count: u32,
    marked: bool,
    magic_number: u64 = 0xDEADBEEF,  // 添加
    
    pub fn release(self: *String, allocator: std.mem.Allocator) void {
        std.debug.assert(self.magic_number == 0xDEADBEEF);  // 验证
        // ...
        self.magic_number = 0xDEADDEAD;  // 标记已释放
    }
};
```

### 步骤 3：建立 CI 门禁

```yaml
# .github/workflows/ci.yml
name: CI
on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - name: Run tests
        run: zig build test
      
      - name: Memory check
        run: valgrind --leak-check=full --error-exitcode=1 \
          ./zig-out/bin/zig-php-test
      
      - name: AddressSanitizer
        run: zig build test -fsanitize=address
      
      - name: Check for TODO/简化实现
        run: |
          if grep -r "TODO\|简化实现" src/; then
            exit 1
          fi
```
