### ✅ 通过的测试（13/13）

#### 1. 基本引用迭代器（复合赋值）
```php
$arr = [1, 2, 3, 4, 5];
foreach ($arr as &$v) {
    $v *= 2;
}
// 结果: [2, 4, 6, 8, 10] ✅
```

#### 2. 关联数组引用
```php
$arr = ["a" => 10, "b" => 20, "c" => 30];
foreach ($arr as &$v) {
    $v += 5;
}
// 结果: ["a" => 15, "b" => 25, "c" => 35] ✅
```

#### 3. 嵌套引用迭代
```php
$arr = [1, 2, 3];
foreach ($arr as &$v) {
    $v += 10;
    foreach ($arr as &$w) {
        $w += 1;
    }
}
// 结果: [14, 15, 16] ✅
```

#### 4. 引用后普通迭代
```php
$arr = [5, 10, 15];
foreach ($arr as &$v) {
    $v -= 2;
}
$sum = 0;
foreach ($arr as $v) {
    $sum += $v;
}
// sum = 24 ✅
```

#### 5. 条件修改

## 技术实现

### 核心组件

1. **php_array_iter_init_ref**
   - 初始化时转换数组为mixed模式
   - 确保指针稳定性

2. **php_array_iter_value_ref**
   - 返回指向数组元素的直接指针
   - 使用TYPE_REF标记

3. **php_ref_assign_ptr**
   - 通过alloca指针赋值
   - 支持复合赋值操作

4. **convertToMixed**
   - 转换时retain所有值
   - 避免数据丢失

5. **val_assign**
   - 简化为直接覆盖
   - 支持引用值更新

6. **native_linker特殊处理**
   - php_ref_assign_ptr第一个参数不解引用
   - 直接传递alloca指针

### 性能特点
