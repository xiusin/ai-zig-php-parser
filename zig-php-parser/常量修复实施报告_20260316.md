## 🎓 技术经验

### 1. 常量系统的实现

**位置**: `src/aot/runtime_lib_template.zig`

**初始化流程**:
```zig
pub fn initRuntime(allocator: Allocator) void {
    runtime_allocator = allocator;
    constants = std.StringHashMap(Value).init(runtime_allocator);
    initPredefinedConstants() catch {};
}

fn initPredefinedConstants() !void {
    // 添加常量
    const keys = [_][]const u8{ "PHP_INT_MAX", ... };
    const vals = [_]i64{ std.math.maxInt(i64), ... };
    for (keys, vals) |key, val| {
        const key_copy = try runtime_allocator.dupe(u8, key);
        try constants.put(key_copy, Value.initInt(val));
    }
}
```

**查找流程** (native_linker.zig):
```zig
pub fn getGlobalVar(name: []const u8) runtime.Value {
    // 先查找常量表
    if (runtime.constants.get(name)) |const_val| {
        _ = const_val.retain();
        return const_val;
    }
    // 再查找全局变量表
    if (global_vars.get(name)) |value| {
        _ = value.retain();
        return value;
    }
    // 未找到，发出警告
    runtime.emitWarning("Undefined variable ...");
    return runtime.Value.initNull();
}
```

### 2. 常量值的选择

**PHP标准值**:
- SORT_ASC = 1 (不是0)
- SORT_DESC = 2
- SORT_REGULAR = 0

**注意**: 必须与PHP标准一致，否则会导致行为差异

### 3. 左移溢出问题

**test_022崩溃**:
```php
$big = PHP_INT_MAX;
$overflow = $big << 1;  // 崩溃！
```

**生成的代码**:
```zig
reg_187 = runtime.Value.initInt(
    reg_185.toInt() << @as(u6, @intCast(@min(63, @max(0, reg_186.toInt()))))
);
```

**问题**: Zig的左移在溢出时会panic  
**PHP行为**: 左移溢出返回负数或0  
**修复**: 需要在codegen中添加溢出检查
