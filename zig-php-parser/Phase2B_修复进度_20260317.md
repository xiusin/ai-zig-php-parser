## 🔧 关键修复

### 1. 签名问题解决

**问题**: needs_allocator = true 但codegen不传allocator

**解决**: 
- 不需要allocator的函数：直接使用asString().data
- 需要allocator的函数：保留allocator参数，正常使用

**模式**:
```zig
// 不需要allocator
pub fn php_unlink(filename: Value) !Value {
    const fname = filename.asString().data;
    // ...
}

// 需要allocator
pub fn php_file_get_contents(filename: Value, allocator: Allocator) !Value {
    const fname = filename.asString().data;
    const content = std.fs.cwd().readFileAlloc(allocator, fname, ...) catch ...;
    // ...
}
```
