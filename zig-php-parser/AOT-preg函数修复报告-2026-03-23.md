## 详细修复内容

### 1. preg_filter() 函数实现

**文件**: `src/runtime/pcre2.zig`, `src/aot/runtime_lib_template.zig`

**功能**: 类似 preg_replace，但只返回匹配的元素

**实现要点**:
- 支持字符串输入：有匹配返回替换后的字符串，无匹配返回 null
- 支持数组输入：只返回有匹配的元素，保持原始键
- 使用 pcre2_substitute_8 进行全局替换
- 正确处理 PHPArray 的迭代（使用 `elements.iterator()`）

**测试结果**:
```
输入: preg_filter('/\d/', 'X', ['a1b2', 'c3d4'])
预期: aXbX,cXdX
实际: aXbX,cXdX ✅
```

### 2. preg_quote() 函数实现

**文件**: `src/runtime/pcre2.zig`, `src/aot/runtime_lib_template.zig`, `src/aot/ir_generator.zig`

**功能**: 转义正则表达式中的特殊字符

**实现要点**:
- 转义字符列表: `.\\+*?[^]$(){}=!<>|:-#`
- 支持可选的 delimiter 参数
- IR 生成器中添加参数填充逻辑（1个参数时自动补 null）
- 使用查找表优化转义判断

**测试结果**:
```
输入: preg_quote('$150.00 (on sale)')
预期: \$150\.00 \(on sale\)
实际: \$150\.00 \(on sale\) ✅
```

### 3. preg_last_error() 函数实现

**文件**: `src/runtime/pcre2.zig`, `src/aot/runtime_lib_template.zig`, `src/aot/native_linker.zig`

**功能**: 返回最后一次 PCRE 正则执行的错误代码

**实现要点**:
- AOT 模式简化实现，总是返回 0 (PREG_NO_ERROR)

**测试结果**:

## 核心问题分析：preg_match_all 引用参数

### 问题描述

```php
preg_match_all('/\d+/', $text, $allMatches);
echo json_encode($allMatches[0]);  // 输出 null，应该输出数字数组
```

### 根本原因

AOT 模式下，引用参数的传递存在问题：

1. **IR 生成阶段** (`src/aot/ir_generator.zig`):
   - 为 preg_match_all 的第3个参数创建了 alloca
   - 记录到 `ref_writebacks` 中，准备写回

2. **代码生成阶段** (`src/aot/native_linker.zig`):
   - 生成的代码使用临时变量传递引用
   - 临时变量在块结束后销毁，修改无法传递回去

### 问题代码示例

```zig
// native_linker.zig 第 8000 行附近
if (is_alloca) {
    try writer.print("reg_{d}", .{matches_arg.id});
} else {
    // ❌ 问题：使用临时变量，块结束后销毁
    try writer.writeAll("blk: { var tmp = reg_");
    try writer.print("{d}; break :blk &tmp; }}", .{matches_arg.id});
}
```

### 修复方向

需要确保引用参数的修改能够传递回原始变量：

1. **方案 A**: 确保所有引用参数都使用 alloca 寄存器
2. **方案 B**: 在函数调用后添加写回逻辑
3. **方案 C**: 修改临时变量的生命周期，使其在函数调用后仍然有效

## 技术要点总结

### 1. AOT 函数参数填充

在 `src/aot/ir_generator.zig` 中，需要为可选参数添加默认值：

```zig
else if (std.mem.eql(u8, func_name, "preg_quote")) {
    if (args.len == 1) {
        const padded = try self.allocator.alloc(Register, 2);
        padded[0] = args[0];
        padded[1] = try self.emitWithResult(.{ .const_null = {} }, .php_value);
        args = padded;
    }
}
```

### 2. 函数 may_raise 标志

在 `src/aot/native_linker.zig` 中，标记不抛出错误的函数：

```zig
.{ "preg_last_error", bi(.{ 
    .runtime_name = "preg_last_error", 
    .needs_allocator = false, 
    .may_raise = false  // 不使用 try
}) },
```

```zig
var iter = subject_arr.elements.iterator();
```
