**文件**: `src/runtime/pcre2.zig`, `src/aot/runtime_lib_template.zig`

**功能**: 类似 preg_replace，但只返回匹配的元素

**实现要点**:
- 支持字符串输入：有匹配返回替换后的字符串，无匹配返回 null
- 支持数组输入：只返回有匹配的元素，保持原始键


### 修复 2: php_preg_replace_callback 完整实现

**问题**: 原实现是一个简化的模板匹配器，只支持 `{{word}}` 和 `{% word %}` 模式，不支持真正的 PCRE 正则表达式。回调函数根本不会被调用。

**根本原因**: 
```zig
// 修复前的简化实现
const is_double_brace = std.mem.indexOf(u8, actual_pat, "\\{\\{") != null;
const is_percent_brace = std.mem.indexOf(u8, actual_pat, "\\{%") != null;
// 对于 /\d+/ 这样的正则，两个条件都是 false，直接返回原字符串
```

**修复方案**: 将完整的 PCRE2 实现从 `src/runtime/pcre2.zig` 移植到 AOT

**关键代码**:
```zig
// 使用 PCRE2 API 进行匹配
const re = getOrCompileRegex(parsed.pattern, parsed.options, allocator) catch { ... };
const match_data = pcre2_match_data_create_from_pattern_8(re, null) orelse { ... };

while (subject_offset < subject_str.len and replace_count < limit) {
    const rc = pcre2_match_8(re, subject_str.ptr, subject_str.len, 
                             @as(c_int, @intCast(subject_offset)), 0, match_data, null);
    if (rc == PCRE2_ERROR_NOMATCH or rc < 0) break;
    
    // 构建匹配数组（包含所有捕获组）
    const matches_arr = try PHPArray.init(allocator);
    var i: usize = 0;
    while (i < @as(usize, @intCast(rc))) : (i += 1) {
        const start = ovec[i * 2];
        const end = ovec[i * 2 + 1];
        const match_str = subject_str[start..end];
        try matches_arr.push(allocator, Value.initString(...));
    }
    
    // 调用回调函数
    const callback_result = try php_invoke_callable(callback, &[_]Value{Value.initArray(matches_arr)}, allocator);
    
    // 处理返回值（支持字符串和整数）
    if (callback_result.isInt()) {
        const int_val = callback_result.asInt();
        var buf: [32]u8 = undefined;
        const int_str = try std.fmt.bufPrint(&buf, "{d}", .{int_val});
        try result.appendSlice(allocator, int_str);
    }
}
```

**测试验证**:
```php
preg_replace_callback('/\d+/', function($m) {
    return (int)$m[0] * 2;
}, '123')

修复前: "123" (回调未被调用，输出 "Callback called with" 为空)
修复后: "246" ✅ (回调正确调用，输出 "Callback called with: 123", "Returning: 246")
```

### 技术要点

1. **类型转换**: `subject_offset` 需要转换为 `c_int` 才能传递给 `pcre2_match_8`
2. **回调调用**: 使用 AOT 的 `php_invoke_callable` 函数，不需要 VM 对象
3. **返回值处理**: 支持字符串和整数类型，整数需要格式化为字符串
4. **内存管理**: 使用 `defer` 确保 `match_data` 和临时数组正确释放
