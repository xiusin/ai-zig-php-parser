# AOT 性能优化总结 - 2026-02-13

## 🎉 重大突破

### 性能进展

| 阶段 | 性能 (ms) | vs PHP | 改善 |
|------|-----------|--------|------|
| 初始 | ~85 | 19x 慢 | - |

## ✅ 完成的优化

### 1. 类型推断框架
- 前向数据流分析
- 推断 phi、常量、cast 类型
- 迭代传播类型信息

### 2. Cast 穿透优化 ⭐
**核心创新：** 比较操作直接使用原始类型，避免装箱

**优化前：**
```
reg_4 = cast reg_15 (i64 → php_value)
reg_6 = lt reg_4 (php_value), reg_5 (i64)
```

**优化后：**
```
reg_6 = lt reg_15 (i64), reg_5 (i64)  // 原生比较
```

### 3. IR 扩展
- move 指令支持
- 所有 switch 分支完整

## ⚠️ 遇到的问题

### 算术操作穿透失败
**问题：** 直接穿透 add/sub 等操作导致运行时死循环

**原因：**
- add 结果赋值给 phi 节点
- phi 类型在 SSA 重命名后确定
- 类型推断缺少反向传播

**解决：** 暂时只优化比较操作（已验证安全）
