## 🎯 下一步计划

### 选项 A: 增强功能（推荐）

#### A1. Foreach 循环支持（P1 - 高优先级）

**目标**: 实现 PHP 的 foreach 循环，支持数组遍历

**实现内容**:
```php
// 基本 foreach
foreach ($array as $value) {
    echo $value;
}

// 带键的 foreach
foreach ($array as $key => $value) {
    echo "$key: $value";
}
```

**预计工作量**: 4-6 小时

**技术要点**:
- 实现数组迭代器
- 生成循环结构的 IR
- 处理键值对
- 支持 break/continue

#### A2. 位运算符（P2 - 中优先级）

**目标**: 实现 PHP 的位运算符

**实现内容**:
```php
$a & $b   // 按位与
$a | $b   // 按位或
$a ^ $b   // 按位异或
~$a       // 按位非
$a << $b  // 左移
$a >> $b  // 右移
```

**预计工作量**: 2-3 小时

**技术要点**:
- 实现 6 个位运算函数
- 添加 IR 指令支持
- 生成 Zig 代码

#### A3. 三元运算符（P2 - 中优先级）

**目标**: 实现 PHP 的三元运算符

**实现内容**:
```php
$result = $condition ? $true_value : $false_value;
$result = $value ?: $default;  // 短路三元
```

**预计工作量**: 2-3 小时

**技术要点**:
- 解析三元表达式
- 生成条件分支 IR
- 处理短路求值

#### A4. 递增递减运算符（P2 - 中优先级）

**目标**: 实现 ++/-- 运算符

**实现内容**:
```php
$a++;  // 后置递增
++$a;  // 前置递增
$a--;  // 后置递减
--$a;  // 前置递减
```

**预计工作量**: 2-3 小时

#### A5. 复合赋值运算符（P2 - 中优先级）

**目标**: 实现复合赋值运算符

**实现内容**:
```php
$a += $b;   // 加法赋值
$a -= $b;   // 减法赋值
$a *= $b;   // 乘法赋值
$a /= $b;   // 除法赋值
$a %= $b;   // 取模赋值
$a .= $b;   // 字符串连接赋值
```

**预计工作量**: 2-3 小时

#### A6. 更多数组函数（P2 - 中优先级）

**目标**: 实现更多 PHP 数组函数

**实现内容**:
```php
array_merge($arr1, $arr2)     // 合并数组
array_slice($arr, $offset)    // 切片
array_filter($arr, $callback) // 过滤
array_map($callback, $arr)    // 映射
array_keys($arr)              // 获取键
array_values($arr)            // 获取值
sort($arr)                    // 排序
```

**预计工作量**: 6-8 小时

### 选项 B: 性能优化（推荐）

#### B1. 常量折叠（P2 - 编译时优化）

**目标**: 在编译时计算常量表达式

**示例**:
```php
$x = 10 + 20;  // 编译时计算为 30
$y = 5 * 6;    // 编译时计算为 30
```

**预计工作量**: 4-6 小时

**技术要点**:
- 在 IR 生成阶段识别常量表达式
- 编译时求值
- 替换为常量值

#### B2. 死代码消除（P2 - 编译时优化）

**目标**: 移除永远不会执行的代码

**示例**:
```php
if (false) {
    echo "Never executed";  // 移除
}
```

**预计工作量**: 3-4 小时

#### B3. 内联小函数（P2 - 运行时优化）

**目标**: 将小函数内联到调用点

**示例**:
```php
function add($a, $b) { return $a + $b; }
$x = add(10, 20);  // 内联为: $x = 10 + 20;
```

**预计工作量**: 4-6 小时

#### B4. 字符串池化（P2 - 内存优化）

**目标**: 复用相同的字符串字面量

**预计工作量**: 3-4 小时

**技术要点**:
- 在编译时收集所有字符串字面量
- 生成字符串池
- 引用池中的字符串
