**优先级**: P1 - 高优先级  
**预计时间**: 2-3小时  
**状态**: 准备开始

#### 功能需求

```php
// 前置递增/递减
++$a;  // 先加1，返回新值
--$a;  // 先减1，返回新值

// 后置递增/递减
$a++;  // 先返回旧值，再加1
$a--;  // 先返回旧值，再减1
```

#### 实施步骤

1. **Parser修改** - 添加前置和后置运算符解析
2. **AST节点** - 定义`prefix_expr`和`postfix_expr`节点
3. **IR生成** - 生成递增递减的IR指令
4. **代码生成** - 生成Zig代码
5. **测试验证** - 创建测试用例

#### 技术要点

- **前置**: 先修改值，返回新值
- **后置**: 先保存旧值，修改值，返回旧值
- **类型处理**: 支持整数和浮点数
- **副作用**: 确保变量被正确修改
