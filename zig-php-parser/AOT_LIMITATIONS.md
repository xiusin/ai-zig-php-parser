# AOT编译器已知限制

## 正则表达式支持

### preg_match() 限制

**当前实现**: 简化版字面量匹配  
**完整实现**: 解释器和Bytecode VM使用PCRE2

#### 支持的模式

```php
// ✅ 字面量匹配
preg_match('/PROD/', 'PROD_123')  // 返回 1
preg_match('/test/', 'testing')   // 返回 1
```

#### 不支持的模式

```php
// ❌ 正则语法
preg_match('/PR.*D/', 'PROD')     // AOT返回0，解释器返回1
preg_match('/\d+/', 'test123')    // AOT返回0，解释器返回1
preg_match('/[a-z]+/', 'abc')     // AOT返回0，解释器返回1
preg_match('/^start/', 'start')   // AOT返回0，解释器返回1
```

### 行为差异

| 模式 | 解释器 | Bytecode | AOT |
|------|--------|----------|-----|
| 字面量 | ✅ | ✅ | ✅ |
| 通配符 `.` | ✅ | ✅ | ❌ |
| 量词 `*+?` | ✅ | ✅ | ❌ |
| 字符类 `[]` | ✅ | ✅ | ❌ |
| 锚点 `^$` | ✅ | ✅ | ❌ |
| 转义 `\d\w` | ✅ | ✅ | ❌ |

### 解决方案

**临时方案**: 使用字面量匹配或`str_contains()`

```php
// 替代方案
if (str_contains($str, 'PROD')) {
    // 字面量匹配
}
```

**长期方案**: 集成PCRE2库（计划中）

## 其他限制

### 生成器 (Generators)

**状态**: 未实现  
**影响**: `yield`关键字不支持

### 动态特性

**状态**: 部分支持  
**限制**:
- `eval()` - 不支持
- `create_function()` - 不支持
- 动态类名实例化 - 部分支持
