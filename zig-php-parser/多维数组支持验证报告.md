```zig
    const array = try self.formatRegister(op.array);

```

### 2. 多维数组工作原理

多维数组通过**递归的 array_get 操作**实现：

```php
$matrix[0][1]
```

编译为：
1. `array_get($matrix, 0)` → 返回子数组
2. `array_get(子数组, 1)` → 返回最终值

每次 `array_get` 操作返回一个 `Value` 类型，如果该值是数组，可以继续进行 `array_get` 操作。

### 3. 支持的功能

```php

```

#### ✅ 三维数组访问
```php
$cube = [[[1, 2], [3, 4]], [[5, 6], [7, 8]]];

```

#### ✅ 四维及更高维度数组
```php
$four_d = [[[[1]]]];
echo $four_d[0][0][0][0];  // 输出: 1
```

#### ✅ 动态创建多维数组
```php

$data[0][0] = 10;

```

#### ✅ 多维数组元素修改
```php
$matrix = [[1, 2], [3, 4]];
$matrix[0][1] = 99;
echo $matrix[0][1];  // 输出: 99
```

#### ✅ 混合索引多维数组
```php
$mixed = [];
$mixed[0] = [];
$mixed[0][1] = 200;
echo $mixed[0][1];  // 输出: 200
```

## 技术细节

### IR 生成流程
```
PHP: $matrix[0][1]
  ↓
AST: ArrayAccess(ArrayAccess($matrix, 0), 1)
  ↓
IR:  %0 = array_get $matrix, 0
     %1 = array_get %0, 1
  ↓
Zig: reg_0 = var_matrix.asArray().get(ArrayKey{.integer = 0}) orelse Value.initNull();
     reg_1 = reg_0.asArray().get(ArrayKey{.integer = 1}) orelse Value.initNull();
```

### 运行时函数
```zig
// 获取数组元素（支持嵌套）
pub fn php_array_get_int(arr: *PHPArray, key: i64) *PHPValue {
    if (arr.get(.{ .int = key })) |val| {
        php_gc_retain(val);  // 引用计数管理
        return val;
    }
    return &null_value;
}
```

## 限制和注意事项

### 2. 性能考虑
- 每次数组访问都是一次函数调用
- 深层嵌套会产生多次函数调用开销
- 建议：对于频繁访问的深层元素，考虑缓存到局部变量

### 3. 内存管理
- 子数组使用引用计数管理
- 修改子数组元素会正确更新引用
- 无需手动释放内存
