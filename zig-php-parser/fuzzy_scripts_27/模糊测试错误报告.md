## AOT功能缺陷汇总

### 1. 缺失的内置函数/类
- `is_infinite()`, `is_nan()`, `is_finite()`
- `set_error_handler()`, `restore_error_handler()`
- `rot13()`
- `getmypid()`, `gethostname()`
- `gethostbyname()`, `dns_get_record()`
- `DateTimeZone`, `DateTime`, `DateInterval` 等日期时间类
- `ArrayObject`, `ArrayIterator`, `SplStack`, `SplQueue`
- `iterator_to_array()`
- `interface_exists()`, `class_exists()`, `trait_exists()`
- `is_scalar()`, `is_countable()`
- `strchr()` (别名strstr)
- `fdiv()`
- WeakMap, WeakReference
- stream_wrapper_register
- `array_push()`, `array_pop()`, `array_slice()` 等数组函数

### 2. 编译时问题
- 函数参数数量不匹配（json_encode, preg_match, array_column, mt_rand等）
- Trait方法冲突检测和处理
- 引用类型参数传递
- 闭包use语法处理
- 可变参数处理

### 3. 运行时问题
- 枚举常量继承
- 字符串null安全运算符与isset行为差异
- 异常处理finally块执行顺序
- match表达式unreachable崩溃
- 常量表达式计算

### 4. 类型系统问题
- 资源类型处理
- 交叉类型和联合类型
- 只读属性
- 动态属性（PHP 8.2+）

## 建议修复优先级

### 高优先级
1. 修复match表达式崩溃问题
2. 修复函数参数数量不匹配问题
3. 实现缺失的数组函数
4. 修复常量表达式计算

### 中优先级
1. 修复字符串nullsafe与isset行为差异
2. 实现DateTime相关类
3. 实现WeakMap/WeakReference
4. 修复枚举常量继承

### 低优先级
1. 实现更多字符串函数
2. 实现迭代器相关类
3. 实现反射相关扩展
4. 实现输出缓冲函数
