## 📋 精准测试策略

### 原则
1. **只测试修复的脚本** - 不浪费时间全量测试
2. **批量测试同类修复** - 一次修复多个函数后批量测试
3. **快速验证** - 每个脚本5秒超时

### 测试脚本模板

```bash
#!/bin/bash
# 精准测试指定脚本

SCRIPTS=(
    "fuzzy_scripts/failed/test_006_string_functions.php"
    "fuzzy_scripts/failed/test_028_builtin_functions.php"
)

for script in "${SCRIPTS[@]}"; do
    echo "Testing: $script"
    timeout 5 ./zig-out/bin/php-interpreter --compile "$script" -o /tmp/test_$$ 2>&1 | grep -E "Success|error:" | head -1
    if [ -f /tmp/test_$$ ]; then
        /tmp/test_$$ > /tmp/aot_output_$$ 2>&1
        php "$script" > /tmp/php_output_$$ 2>&1
        if diff -q /tmp/aot_output_$$ /tmp/php_output_$$ > /dev/null; then
            echo "  ✅ PASS"
        else
            echo "  ⚠️  MISMATCH"
        fi
        rm -f /tmp/test_$$ /tmp/aot_output_$$ /tmp/php_output_$$
    else
        echo "  ❌ COMPILE_FAIL"
    fi
    echo ""
done
```
