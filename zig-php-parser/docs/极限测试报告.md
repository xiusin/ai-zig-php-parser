**示例代码**：

### 2. 超级疯狂测试 (test_mega_crazy.php)

**测试内容**：
- ✅ 1000次循环 + 复杂数学运算
- ✅ 100次深度嵌套字符串拼接
- ✅ 50个元素的复杂数组操作
- ✅ 10层嵌套运算
- ✅ 100次混合所有操作
- ✅ 50次字符串处理链
- ✅ 终极组合：所有功能 + 大量运算

**示例代码**：
```php
// 1000次循环
$mega_sum = 0;
$i = 1;
while ($i <= 1000) {
    $temp = intval(sqrt(pow($i, 2)) + floatval(strval($i)));
    $mega_sum = $mega_sum + $temp;
    $i = $i + 1;
}

// 10层嵌套
$base = 2;
$layer1 = pow($base, 2);
$layer2 = sqrt($layer1 * 4);
$layer3 = round($layer2 + 3.7);
$layer4 = abs($layer3);
$layer5 = intval(floatval(strval($layer4)));
$layer6 = $layer5 * 2;
$layer7 = $layer6 + 10;
$layer8 = pow($layer7, 2);
$layer9 = sqrt($layer8);
$layer10 = round($layer9);
```

**结果**：
- 编译时间: ~1s
- 运行时间: 0.009s (AOT) vs 更慢 (解释)
- 输出: ✅ 完全一致
