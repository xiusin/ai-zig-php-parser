### 函数默认参数 ✅

**问题**: `has_arg` 指令生成错误的代码

**修复**: 
```zig
// 修改前
try self.writeRegAssignmentFmt(writer, reg.id, "(args.len > {d}) and !args[{d}].isMissing();\n", .{ op.index, op.index });

// 修改后
try self.writeRegAssignmentFmt(writer, reg.id, "runtime.Value.initBool((args.len > {d}) and !args[{d}].isMissing());\n", .{ op.index, op.index });
```

**测试**:

- ✅ 多个默认参数
- ✅ 默认参数为常量

### P1 问题（2个，约 8-12 小时）

#### 1. 全局变量支持
**状态**: ⚠️ 编译通过但功能不正确

**问题**: 
- `global` 关键字被识别但不共享变量
- 全局变量在函数中为空或默认值

**需要实现**:
1. 创建全局变量表（类似 `$GLOBALS`）
2. 修改 IR 生成器处理 `global` 语句
3. 在函数中访问全局变量表
4. 处理全局变量的读写

**工作量**: 4-6 小时

**技术难度**: 中等

---

#### 2. 三维及以上数组支持
**状态**: ⚠️ 需要显式初始化

**问题**:
- 当前只支持二维数组的 auto-vivification
- 三维数组 `$cube[0][0][0] = 1` 会崩溃

**需要实现**:
1. 递归收集所有嵌套键
2. 逐层生成 auto-vivification 代码
3. 使用条件跳转和 phi 节点
