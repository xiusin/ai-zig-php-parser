## 🔴 问题1：test_059 - Trait 别名方法未生成

### 测试代码

```php
<?php
trait A { public function foo() { return "A"; } }
trait B { public function foo() { return "B"; } }
class MyClass {
    use A, B { A::foo insteadof B; B::foo as bar; }
}
$obj = new MyClass();
echo $obj->foo() . $obj->bar();
```

**期望输出**: `AB`  
**实际输出**: `error: MethodNotFound` (bar 方法不存在)

### 根本原因

**Trait 冲突解决语法**:
- `A::foo insteadof B` - 使用 A 的 foo，忽略 B 的 foo
- `B::foo as bar` - 将 B 的 foo 重命名为 bar

**当前实现问题**:
1. `insteadof` 正确处理（foo 方法存在）
2. `as` 别名未生成新方法（bar 方法不存在）

**问题**: IR 生成了 `bar()` 调用，但类定义中没有 `bar` 方法。

fn generateUseStatement(self: *IRGenerator, use_node: *ast.UseNode) !void {
    const full_name = use_node.name;  // "App\\Service"
    
    if (use_node.alias) |alias| {
        // use App\Service as S
