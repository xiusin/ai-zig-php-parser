# 运行时函数修复报告

## 修复的问题

### 1. intval() 处理浮点数字符串

**问题描述**:
```php
intval("168.67")  // 返回 0，应返回 168
intval("123.45")  // 返回 0，应返回 123
```

**根本原因**:
- `std.fmt.parseInt()` 无法解析包含小数点的字符串
- 直接返回错误，导致 catch 返回 0

**解决方案**:
1. 检测字符串中是否包含小数点
2. 如果包含，先用 `parseFloat()` 解析为浮点数
3. 然后用 `@intFromFloat()` 转换为整数

**修复位置**:
- `src/runtime/stdlib.zig:3968-3990` (VM 版本)
- `src/runtime/core/type_functions.zig:45-78` (AOT 版本)

**测试结果**:
```php
✅ intval("168.67") = 168
✅ intval("123.45") = 123
✅ intval("-45.67") = -45
✅ intval("3.14159") = 3
```
