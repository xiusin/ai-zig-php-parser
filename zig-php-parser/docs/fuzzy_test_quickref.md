## 🚨 P0 - 立即修复

### foreach 循环

**问题**: `InvalidOpcode: opcode=0x7e(foreach_init)`

**原因**: VM 未实现 foreach 指令

**影响**: 3 个测试失败，无法遍历数组

**工作量**: 10-16 小时

**计划**: 见 `docs/foreach_implementation_plan.md`
