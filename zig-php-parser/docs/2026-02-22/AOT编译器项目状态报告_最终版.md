### 3. test_math_bitwise（类型传播问题）
**状态**：编译错误  
**优先级**：低  
**原因**：
- Phi 节点的类型传播不完整
- 当 phi 节点的 incoming 值类型不一致时，类型传播失败
- 例如：`$min = $numbers[0]` 在循环中

**技术细节**：
```
错误：expected type 'i64', found 'runtime_lib.Value'
位置：phi 节点的初始化代码
原因：reg_57 (phi) 是 i64，但 reg_10 (incoming) 是 Value
```

**解决方案**：
- 需要实现双向类型传播
- 或在代码生成时自动插入类型转换

**预计工作量**：10-15 小时

**建议**：作为类型推断系统改进的一部分
