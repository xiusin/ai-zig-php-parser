**预计时间**：4-6 小时

#### 2. Alloca 寄存器检测问题
**症状**：在 `__main__` 函数中，alloca 寄存器没有正确使用 `.*` 操作符

**影响**：
- test_closures.php Zig 编译失败
- 错误：`expected type '*runtime_lib.Value', found 'runtime_lib.Value'`

**根本原因**：
- `current_alloca_regs` 在某些情况下没有正确设置
- 或者代码生成时没有正确检查 alloca 状态

**解决方案**：
- 调试 alloca 寄存器的检测逻辑
- 确保所有 alloca 寄存器都正确使用 `.*`

**预计时间**：2-3 小时

## 技术细节

### 闭包实现架构

1. **IR 生成阶段**（`ir_generator.zig`）：
   - 解析闭包语法
   - 收集捕获变量
   - 生成匿名函数
   - 创建 `closure_new` IR 操作

2. **代码生成阶段**（`native_linker.zig`）：
   - 生成闭包函数代码
   - 生成 `php_create_closure` 调用
   - 处理 `capture_get` 操作
   - 处理 `call_indirect` 操作

3. **运行时阶段**（`runtime_lib_template.zig`）：
   - `PHPClosure` 结构体
   - `php_create_closure`：创建闭包对象
   - `php_invoke_callable`：调用闭包

### 已知限制

1. **不支持引用捕获**：
   - 当前实现支持值捕获
   - 引用捕获（`use (&$var)`）未完全测试

2. **不支持 $this 绑定**：
   - 闭包中的 `$this` 未实现
   - 需要 `closure_bind` 操作

3. **性能未优化**：
   - 每次调用都通过 `php_invoke_callable`
   - 可以优化为直接函数调用
