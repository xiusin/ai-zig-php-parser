## 本次修复

### 修复 7：嵌套三元运算符 Phi 节点 ⭐⭐
**优先级**：P8（低）

**问题描述**：
- 嵌套三元运算符触发 "reached unreachable code" panic
- 例如：`$a ? "A" : ($b ? "B" : "C")`

**根本原因**：
```zig
// 问题代码
incoming[0] = .{ .value = then_reg, .block = then_block };
incoming[1] = .{ .value = else_reg, .block = else_block };
// ❌ 当 else 表达式是嵌套三元时，else_reg 来自嵌套的 merge 块，不是 else_block
```

**修复方案**：
```zig
// 记录分支结束时的当前块
const then_end_block = self.current_block.?;
// ...
const else_end_block = self.current_block.?;

incoming[0] = .{ .value = then_reg, .block = then_end_block };
incoming[1] = .{ .value = else_reg, .block = else_end_block };
// ✅ 使用实际的结束块
```

**影响**：
- 单功能测试：5/7 → 6/7 (+14%)
- 三元运算符测试完全通过
- 支持任意深度的嵌套三元运算符

**测试结果**：
```php
$score >= 90 ? "A" :
($score >= 80 ? "B" :
($score >= 70 ? "C" :
($score >= 60 ? "D" : "F")))

// 输出：
// Score 95: Grade A ✅
// Score 85: Grade B ✅
// Score 75: Grade C ✅
// Score 65: Grade D ✅
// Score 55: Grade F ✅
```
