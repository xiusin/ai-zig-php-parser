#### 2. 调查循环中 phi 节点赋值问题
**状态**: 已识别，已文档化  
**问题**: 循环中多个 if 语句修改同一变量时，phi 节点 incoming 值不正确  
**文档**: `docs/known-issues/AOT-PHI-001-nested-if-phi-bug.md`

**根本原因**:
- SSA 构造算法在处理嵌套 if 时，没有正确追踪变量定义
- else 分支错误地使用了前一个 if 的结果，而不是循环开始时的值

**修复方案**:
- 短期: 改进 IR 生成器的变量定义追踪
- 长期: 重构为标准 SSA 构造算法（参考 LLVM mem2reg）

#### 3. PHPString.init 类型不匹配
**状态**: 未复现  
**说明**: 在简单测试中无法复现此问题，可能只在特定复杂场景下出现
