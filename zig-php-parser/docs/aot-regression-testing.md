# AOT 编译器回归测试

## 目的

确保 AOT 编译器的修改不会破坏现有功能（避免"跷跷板"问题）。

## 使用方法

```bash
cd /Users/tuoke/Desktop/ai-zig-php-parser/zig-php-parser
./test_aot_regression.sh
```

## 测试覆盖

| 测试 | 文件 | 重点 |
|------|------|------|
| 斐波那契算法 | test_fibonacci.php | Phi 节点并行赋值 |
| Phi 节点变量交换 | test_phi_swap.php | 变量交换、三变量轮换、循环交换 |
| 电商系统 | test_complex_ecommerce.php | 类、方法、数组、循环 |
| 算法和数据处理 | test_complex_algorithms.php | 斐波那契、质数、排序 |

## 测试策略

1. **精确匹配**：斐波那契、Phi 节点交换
2. **浮点数容忍**：电商系统（忽略精度差异）
3. **关键输出**：算法测试（检查核心算法结果）

## 添加新测试

编辑 `test_aot_regression.sh`，添加：

```bash
test_script "测试名称" "/path/to/test.php" [true/false]
```

第三个参数：
- `true`：忽略浮点数精度差异
- `false` 或省略：精确匹配

## CI 集成

在 `.github/workflows/ci.yml` 中添加：

```yaml
- name: AOT 回归测试
  run: ./test_aot_regression.sh
```

## 故障排查

如果测试失败：

1. 查看差异输出
2. 手动运行 PHP 和 AOT 版本对比
3. 检查是否是预期的行为变化
4. 如果是 bug，修复后重新测试

## 维护

- 每次修改 AOT 编译器后运行
- 添加新功能时添加对应测试
- 定期审查测试覆盖率
