## 📝 技术笔记

### 迭代器设计

```zig
const IteratorState = struct {
    iterable: Value,           // 被遍历的数组/对象
    current_index: i64,        // 当前索引
    keys: ?[]Value,            // 键数组（关联数组）
    is_done: bool,             // 是否完成
};
```

### 指令语义

**foreach_init**:
- 输入: 栈顶是可迭代对象
- 输出: 创建迭代器并压入栈
- 副作用: 无

**foreach_next**:
- 输入: 栈顶是迭代器
- 输出: 如果未完成，压入键和值；否则跳转
- 副作用: 更新迭代器状态
