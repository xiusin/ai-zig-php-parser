## P1 - 重要问题（影响功能）

### 2. 全局变量不支持 ⚠️

**问题**: `global` 关键字不支持

**复现**:
```php
$memo = [];
function fib($n) {
    global $memo;  // 不支持
    // ...
}
```

**当前行为**: 全局变量被初始化为 `null`，导致崩溃

**解决方案**: 使用参数传递或类属性

**工作量**: 4-6 小时

**优先级**: P1

---

### 3. 函数默认参数有 bug ⚠️

**问题**: 函数默认参数生成错误的代码

**复现**:
```php
function factorial($n, $acc = 1) {  // 编译错误
    // ...
}
```

**错误信息**: `expected type 'runtime_lib.Value', found 'bool'`

**解决方案**: 暂时不使用默认参数

**工作量**: 2-3 小时

**优先级**: P1

---

### 4. 三维及以上数组需要显式初始化 ⚠️

**问题**: 三维数组的 auto-vivification 不支持

**复现**:
```php
$cube = [];
$cube[0][0][0] = 1;  // 崩溃
```

**当前支持**: 二维数组完全支持

**解决方案**: 
```php
// 方案 A: 显式初始化
$cube = [];
$cube[0] = [];
$cube[0][0] = [];
$cube[0][0][0] = 1;  // ✅

// 方案 B: 逐层赋值
$cube = [];
$cube[0][0] = [];
$cube[0][0][0] = 1;  // ✅
```

**修复**: 需要递归处理所有嵌套层级

**工作量**: 2-3 小时

**优先级**: P1
