## 已知问题列表

### 1. 三元运算符条件类型 (P1)

**问题**: 三元运算符的条件表达式生成 `Value` 类型，但 `if` 语句期望 `bool`

**错误信息**:
```
.zigphp_aot_build/main.zig:1882:21: error: expected type 'bool', found 'runtime_lib.Value'
                if (reg_122) {
                    ^~~~~~~
```

**复现代码**:
```php
$condition = true;
$result = $condition ? 100 : 200;
```

**影响范围**: 所有使用三元运算符的代码

**临时方案**: 使用 if-else 替代三元运算符

**修复方向**: 在生成三元运算符的条件判断时，添加 `.toBool()` 转换

---

### 2. 多维数组对齐问题 (P1)

**问题**: 多维数组访问时出现 `incorrect alignment` 错误

**错误信息**:
```
thread panic: incorrect alignment
runtime_lib.zig:1591:16: in asArray
        return @ptrFromInt(nanbox_abi.decodePtr(self.val));
```

**复现代码**:
```php
$matrix = [];
for ($i = 0; $i < 3; $i++) {
    for ($j = 0; $j < 3; $j++) {
        $matrix[$i][$j] = $i * 3 + $j;
    }
}
```

**影响范围**: 所有多维数组操作

**临时方案**: 避免使用多维数组，使用一维数组模拟

**修复方向**: 检查 nanbox 指针对齐，确保数组指针正确对齐

---

### 3. implode 函数未实现 (P2)

**问题**: `implode()` 函数未在运行时库中实现

**错误信息**:
```
error: CompilationFailed
```

**复现代码**:
```php
$arr = [1, 2, 3];
echo implode(", ", $arr);
```

**影响范围**: 使用 `implode()` 的代码

**临时方案**: 手动循环拼接字符串

**修复方向**: 在 `runtime_lib.zig` 中实现 `php_implode` 函数

---

### 4. 字符串索引访问 (P2)

**问题**: 字符串索引访问可能有问题

**复现代码**:
```php
$str = "hello";
$char = $str[0];  // 可能失败
```

**影响范围**: 字符串索引访问

**临时方案**: 使用 `substr()` 函数

**修复方向**: 实现字符串索引访问的运行时支持
