# 引用迭代（Foreach by Reference）问题报告

## 问题描述
PHP 的 `foreach ($arr as &$v)` 引用迭代功能在所有执行模式下都不工作。

## 影响范围
- **优先级**: P0（核心语言特性）
- **影响模式**: 
  - ✅ Tree-walking 解释器
  - ❌ Bytecode VM
  - ❌ AOT 编译器

## 复现步骤

```php
<?php
$arr = [1, 2, 3];
foreach ($arr as &$v) {
    $v *= 2;
}
print_r($arr);
```

**期望输出**:
```
Array
(
    [0] => 2
    [1] => 4
    [2] => 6
)
```

**实际输出**:
```
Array
(
    [0] => 1
    [1] => 2
    [2] => 3
)
```

## 根本原因分析

### AOT 模式
在 `runtime_lib_template.zig` 中，`php_array_iter_value_ref` 函数存在问题：

1. **Packed 模式**：返回迭代器内部临时字段 `self.value` 的指针
2. **问题**：下次迭代时 `self.value` 被覆盖，导致引用失效

### 解释器模式
- Bytecode VM：`foreach_init` 操作码未实现（InvalidOpcode）
- Tree-walking：引用语义未正确实现

## 修复方案

### AOT 模式修复（已在文档中提出）
```zig
pub fn php_array_iter_value_ref(iter_val: Value) !Value {
    const iter_addr = iter_val.asInt();
    if (iter_addr == 0) return Value.initNull();
    const iter: *ArrayIterator = @ptrFromInt(@as(usize, @intCast(iter_addr)));
    
    // 返回实际数组元素指针，而非迭代器临时字段
    if (iter.iter.mixed_it) |*mixed_it| {
        if (iter.current) |entry| {
            const mutable_ptr: *Value = @constCast(entry.value_ptr);
            return Value.initRef(mutable_ptr);
        }
    } else {
        // Packed 模式：返回数组中实际元素的指针
        if (iter.iter.index > 0 and iter.iter.index <= iter.iter.elements.packed_values.items.len) {
            const actual_index = iter.iter.index - 1;
            const elem_ptr = &iter.iter.elements.packed_values.items[actual_index];
            const mutable_ptr: *Value = @constCast(elem_ptr);
            return Value.initRef(mutable_ptr);
        }
    }
    return Value.initNull();
}
```

### Bytecode VM 修复
需要实现 `foreach_init` 和 `foreach_next` 操作码的引用模式支持。

### Tree-walking 修复
需要在 AST 执行器中正确处理引用赋值。

## 测试用例

### 基础测试
```php
$arr = [1, 2, 3];
foreach ($arr as &$v) {
    $v *= 2;
}
// 期望: [2, 4, 6]
```

### 关联数组测试
```php
$arr = ['a' => 1, 'b' => 2];
foreach ($arr as $k => &$v) {
    $v += 10;
}
// 期望: ['a' => 11, 'b' => 12]
```

### 嵌套引用测试
```php
$arr = [[1, 2], [3, 4]];
foreach ($arr as &$sub) {
    foreach ($sub as &$v) {
        $v *= 2;
    }
}
// 期望: [[2, 4], [6, 8]]
```

## 优先级理由
这是 PHP 的核心特性，许多实际代码依赖引用迭代来修改数组元素。不支持此特性会严重限制解释器的实用性。
