## 快速命令

```bash
# 编译
zig build

# 运行测试
./zig-out/bin/php-interpreter script.php

# AOT编译
./zig-out/bin/php-interpreter --compile script.php

# 查看IR
./zig-out/bin/php-interpreter --compile script.php --dump-ir

# 优化编译
./zig-out/bin/php-interpreter --compile script.php --optimize=release-safe
```

## 常见问题

### Q: 为什么引用传递慢？
A: retain/release开销。优化后预期快2-5倍。

### Q: Generator何时支持？
A: 已放弃（需要15-20小时状态机实现）。

### Q: 如何提升性能？
A: 
1. 生命周期分析（10-15h，5-10x提升）
2. 引用计数消除（5-8h，2-3x提升）
3. 函数内联（3-5h，2x提升）

### Q: 测试文件在哪？
A: `test_scripts/fuzzy/test_*.php`（在.gitignore中）
