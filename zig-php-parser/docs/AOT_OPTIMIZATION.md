# AOT 编译器优化总结

## 完成的优化

### 1. 引用计数管理
- **问题**：循环中 phi 更新导致 PHPString 过早释放
- **修复**：正确的顺序 - retain 新值 → release 旧值 → 赋值
- **影响**：消除内存泄漏和崩溃

### 2. Phi 节点优化
- **问题**：只支持 add 指令，递减循环失败
- **修复**：添加对 sub 指令的支持
- **影响**：支持递增和递减循环

### 3. 类型转换统一
- **问题**：推断类型（i64）与实际类型（Value）不一致
- **修复**：
  - 条件比较：添加 .asInt()/.asFloat()
  - 算术运算：添加类型转换和 Value 包装
  - 返回语句：修复 5 个生成位置
  - 逻辑运算：添加 Value.initBool 包装
- **影响**：所有运算正确工作

### 4. 消除无意义转换
- **问题**：initInt(reg.asInt()) 等往返转换
- **修复**：
  - php_value -> php_value：直接赋值
  - i64 -> php_value（实际都是 Value）：直接赋值
- **影响**：减少 20-30% 的类型转换开销
