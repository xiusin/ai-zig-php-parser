## 问题修复

### 问题1：属性测试框架错误处理

**问题描述**：
- 原始实现中，`property` 函数抛出的错误没有被正确捕获
- 导致测试提前终止，通过率计算错误

**解决方案**：
```zig
const result = property(input) catch |err| {
    std.debug.print("Property error at iteration {d}: {}\n", .{i, err});
    failed += 1;
    continue;
};
```

### 问题2：内存泄漏

**问题描述**：
- `loadBaseline` 函数中使用 `allocator.create` 和 `allocator.dupe` 分配内存
- 返回的数据没有提供释放机制
- 导致每次调用都泄漏内存

**解决方案**：
- 直接返回 `parsed.value`（值类型）
- 利用 `defer parsed.deinit()` 自动清理
- 消除额外的内存分配

修改前：
```zig
const baseline = try self.allocator.create(PerformanceBaseline);
baseline.* = parsed.value;
baseline.benchmark_name = try self.allocator.dupe(u8, parsed.value.benchmark_name);
baseline.git_commit = try self.allocator.dupe(u8, parsed.value.git_commit);
return baseline.*;
```

修改后：
```zig
return parsed.value;
```
