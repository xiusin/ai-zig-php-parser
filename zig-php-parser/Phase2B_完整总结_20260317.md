## 🏗️ 架构发现

### Value的48位整数限制

**设计**: NaN boxing，48位有符号整数  
**范围**: -140737488355328 到 140737488355327  
**影响**: PHP_INT_MAX无法精确存储

**解决方案**:
- 短期: 接受限制，使用48位值
- 长期: 重新设计Value（见value_v2_design.md）

### 函数签名模式

**模式A** - 不需要allocator:
```zig
pub fn php_func(arg: Value) !Value {
    const data = arg.asString().data;
    // 直接使用，不分配内存
}
// 注册: needs_allocator = false
```

**模式B** - 需要allocator:
```zig
pub fn php_func(arg: Value, allocator: Allocator) !Value {
    const data = arg.asString().data;
    const result = try allocator.alloc(...);
    // 分配内存
}
// 注册: needs_allocator = true
```

**模式C** - 使用全局allocator:
```zig
pub fn php_func(arg: Value) !Value {
    const global_alloc = std.heap.page_allocator;
    const result = try global_alloc.alloc(...);
    // 用于签名不匹配的情况
}
// 注册: needs_allocator = false
```
