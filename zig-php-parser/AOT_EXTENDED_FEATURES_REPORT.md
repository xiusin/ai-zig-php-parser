## 💡 技术实现

### 比较运算符实现

```zig
.eq => |op| {
    if (inst.result) |reg| {
        const type_tag = @as(std.meta.Tag(IR.Type), reg.type_);
        if (type_tag == .bool) {
            // 直接bool比较（高性能）
            try writer.print("reg_{d} = reg_{d} == reg_{d};\n", ...);
        } else {
            // 使用运行时函数（通用）
            try writer.print("reg_{d} = try runtime.php_eq(reg_{d}, reg_{d});\n", ...);
        }
    }
},
```

### 智能优化

1. **类型特化**
   - i64类型：直接生成机器指令
   - Value类型：调用运行时函数

2. **零成本抽象**
   - 编译时决策
   - 运行时无分支

3. **内联优化**
   - 简单运算直接内联
   - 复杂运算调用函数
