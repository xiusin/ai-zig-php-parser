## 💡 技术亮点

### 1. SSA形式的优雅实现

```zig
// 后置递增：$a++
const old_value = load($a);    // 旧值自动保存
const new_value = add(old_value, 1);
store($a, new_value);
return old_value;              // 直接返回旧值
```

**优势**：
- 无需显式保存旧值
- 代码简洁清晰
- 便于编译器优化

### 2. 统一的IR表示

前置和后置使用相同的IR指令，仅返回值不同：

```
前置 ++$a: load → add → store → 返回 new_value
后置 $a++: load → add → store → 返回 old_value
```

### 3. 正确的求值顺序

```php
$i = 10;
$j = ++$i + $i++;
// 1. ++$i: i=11, 返回11
// 2. $i++: 返回11, i=12
// 3. 11 + 11 = 22 ✅
```

## 🎓 学习要点

### 前置 vs 后置的关键区别

```
前置 ++$a:
  1. 修改变量
  2. 返回新值
  
后置 $a++:
  1. 保存旧值
  2. 修改变量
  3. 返回旧值
```

### IR生成的关键

```zig
// 前置
const new_value = add(operand, 1);
store(var, new_value);
return new_value;  // 返回新值

// 后置
const old_value = operand;  // SSA自动保存
const new_value = add(operand, 1);
store(var, new_value);
return old_value;  // 返回旧值
```
