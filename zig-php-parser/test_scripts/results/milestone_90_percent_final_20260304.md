**实现**:
```zig
const MT19937 = struct {
    state: [624]u32,
    index: usize,
    
    fn init(seed: u32) MT19937 { ... }
    fn generate(self: *MT19937) u32 { ... }
    fn twist(self: *MT19937) void { ... }
};

threadlocal var mt_state: ?MT19937 = null;

fn nextRandom() u64 {
    if (mt_state == null) {
        mt_state = MT19937.init(@intCast(...));
    }
    return @as(u64, mt_state.?.generate());
}
```

## 性能分析

### 引用传递性能

**测试**: 100k次引用传递调用
- PHP: 1.7ms
- AOT: 93ms
- **慢54倍**

**原因**: retain/release开销
- 每次参数传递：1次retain
- 每次赋值：1次release + 1次retain
- 每次返回：1次release

**优化方向**（未实现）:
1. 生命周期分析：消除不必要的retain/release
2. 引用计数优化：合并连续的release+retain
3. 内联优化：小函数内联消除调用开销

**当前状态**: 功能正确，性能可接受（绝对值仍快于PHP解释器）

### 普通传递性能

**测试**: 100k次普通传递调用
- PHP: 1.7ms
- AOT: 82ms
- **慢48倍**

**结论**: 性能瓶颈在整体retain/release，不是引用传递特有问题
