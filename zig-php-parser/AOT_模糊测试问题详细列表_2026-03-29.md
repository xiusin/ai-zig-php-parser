## 九、修复建议汇总

### 需要新增的内置函数 (按优先级)

```
P1 - 高频使用:
- log2()
- getdate()
- password_hash()
- array_find()
- iterator_to_array()

P2 - 中频使用:
- enum_exists()
- hash_algos()
- rewind()
- get_resource_type()
- stream_register_wrapper()
- gethostbyaddr()

P3 - 低频使用:
- fsockopen()
- stream_socket_client()
- curl_init()
- getmxrr()
- checkdnsrr()
- compact()
- extract()
```

### 需要实现的SPL类

```
P1:
- SplStack (top, pop方法)
- LimitIterator
- FilterIterator完整实现

P2:
- CachingIterator
- AppendIterator
- CallbackFilterIterator
- SplMinHeap
```

### 需要支持的PHP 8.1+语法

```
P1:
- Property hooks
- 展开运算符(...$var)
- First-class callable (foo(...))

P2:
- 动态变量($$var)
- 动态属性访问($obj->$prop)
- 部分应用语法
```
