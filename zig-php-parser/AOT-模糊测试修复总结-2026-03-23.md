## 技术要点总结

### 1. 打桩实现识别与升级

**问题模式**:
```zig
pub fn php_preg_match_all(..., matches: *Value, ...) !Value {
    _ = matches;  // ❌ 完全忽略引用参数
    return Value.initInt(count);
}
```

**解决方案**: 替换为完整的 PCRE2 实现，正确填充引用参数。

### 2. 函数签名与 may_raise 标志

**错误**: 函数返回 `!Value` 但标记为 `may_raise = false`
```zig
pub fn php_json_last_error() !Value {  // ❌ 错误联合类型
    return Value.initInt(last_json_error_code);
}
```

**修复**: 改为直接返回 `Value`
```zig
pub fn php_json_last_error() Value {  // ✅ 直接返回
    return Value.initInt(last_json_error_code);
}
```

### 3. 枚举值冲突处理

添加新枚举值时，需要更新所有后续的枚举值以避免冲突：
```zig
// 添加 log2 = 159 后，需要将所有后续值加1
sin = 160,  // 原来是 159
cos = 161,  // 原来是 160
// ... 依此类推
```

### 4. 线程局部存储

使用 `threadlocal` 关键字确保每个线程有独立的错误状态：
```zig
threadlocal var last_json_error_code: i32 = json_error_none;
```
