## 复用策略

### 1. 直接复用（无需修改）
适用于不依赖 VM 上下文的纯函数：
- `time()`
- `microtime()`
- `random_int()`
- `random_bytes()`

**实现方式**：
1. 从 VM 模块复制函数实现
2. 移除 `vm: *anyopaque` 参数
3. 调整参数为 `Value` 类型
4. 添加 `allocator` 参数（如需要）

### 2. 适配复用（需要修改）
适用于依赖 VM 上下文或需要 allocator 的函数：
- `date()`
- `sleep()`
- `usleep()`
- `shuffle()`
- `array_rand()`

**实现方式**：
1. 复制核心逻辑
2. 替换 VM 上下文访问为直接参数传递
3. 添加 `allocator` 参数
4. 调整错误处理

### 3. 重新实现（差异较大）
适用于需要协程支持或特殊 VM 功能的函数：
- `sleep()` (协程感知)
- `usleep()` (协程感知)

**实现方式**：
1. 使用 Zig 标准库的等效功能
2. 简化实现（移除协程支持）
3. 保持 PHP 语义一致
