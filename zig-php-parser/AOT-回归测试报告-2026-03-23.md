## 修复的问题

### 问题 1: Zig 0.15.2 未使用参数错误

**症状**: AOT 生成的代码中，未使用的函数参数导致编译错误

**根本原因**: Zig 0.15.2 将未使用的函数参数从警告升级为错误

**解决方案**:
1. 在函数体开头添加 `_ = parameter;` 标记参数为故意未使用
2. 只在参数确实未使用时才生成丢弃语句
3. 对于 `aot_dispatch_static_method`，只为有静态方法的类生成分支

**修改文件**: `src/aot/native_linker.zig`

**关键修复**:
```zig
// 修复 1: 在生成的函数中标记 allocator 为故意未使用
try code.appendSlice(self.allocator, "    _ = allocator; // 标记为故意未使用\n");

// 修复 2: 只为有静态方法的类生成分支
var class_has_static_methods = false;
for (type_def.methods) |method| {
    if (method.is_static) {
        class_has_static_methods = true;
        break;
    }
}

// 只为有静态方法的类生成分支
if (!class_has_static_methods) continue;

// 修复 3: 只在完全没有静态方法时标记参数未使用
if (!has_static_methods) {
    try writer.writeAll("    _ = class_name;\n");
    try writer.writeAll("    _ = method_name;\n");
    try writer.writeAll("    _ = args;\n");
    try writer.writeAll("    _ = allocator;\n");
}
```
