## 🔍 问题分析

### 症状

1. **编译成功**：所有语法和类型检查都通过
2. **运行时崩溃**：在generateFunction函数中崩溃
3. **错误类型**："switch on corrupt value"表示内存损坏
4. **调试信息未输出**：崩溃发生在调试print之前

### 可能的根本原因

#### 1. 内存生命周期问题（最可能）
- 某些数据结构在使用时已被释放
- 指针悬垂或use-after-free
- 栈溢出或堆损坏

#### 2. IR结构问题
- BasicBlock的terminator未正确初始化
- 某些块没有terminator
- terminator的内存被覆盖

#### 3. 类型系统问题
- IR类型与生成的代码不一致
- 寄存器类型推断错误
- 指针类型处理不当

#### 4. ArrayList内部问题
- 虽然API已修复，但可能存在内部状态损坏
- items指针可能无效
- capacity或length字段被破坏

### 方案C：检查IR生成

添加IR验证函数：

```zig
fn validateFunction(func: *const Function) !void {
    for (func.blocks.items, 0..) |block, idx| {
        if (block.terminator == null) {
            std.debug.print("[ERROR] Block {d} ({s}) has no terminator!\n", .{ idx, block.label });
            return error.UnterminatedBlock;
        }
        
        // 验证terminator的tag是否有效
        const term = block.terminator.?;
        const tag_name = @tagName(term);
        std.debug.print("[DEBUG] Block {d} terminator: {s}\n", .{ idx, tag_name });
    }
}
```

**优点**：
- 可以在IR生成阶段就发现问题
- 避免生成错误的代码

**缺点**：
- 只能检测IR层面的问题
- 无法检测内存损坏

### 方案D：重写generateFunction（激进）

完全重写generateFunction函数，使用更简单的实现：

```zig
fn generateFunction(self: *Self, writer: anytype, func: *const IR.Function) !void {
    // 1. 简单的函数签名
    try writer.print("fn @\"{s}\"() !runtime.Value {{\n", .{func.name});
    
    // 2. 只生成第一个块的指令
    if (func.blocks.items.len > 0) {
        const block = func.blocks.items[0];
        for (block.instructions.items) |inst| {
            try self.generateInstruction(writer, inst);
        }
    }
    
    // 3. 简单的返回
    try writer.writeAll("    return runtime.Value.initNull();\n");
    try writer.writeAll("}\n");
}
```

**优点**：
- 可以快速验证基本功能
- 排除复杂逻辑的影响

**缺点**：
- 功能不完整
- 只是临时方案

## 🎓 技术收获

### Zig 0.15.2 关键知识

1. **ArrayList是Unmanaged版本**
   - 不再内部存储allocator
   - 所有方法都需要显式传递allocator
   - `.init(allocator)`方法已被移除

2. **正确的初始化方式**
   ```zig
   var list = std.ArrayList(T){};
   defer list.deinit(allocator);
   ```

3. **所有方法都需要allocator**
   ```zig
   try list.append(allocator, item);
   const writer = list.writer(allocator);
   const slice = try list.toOwnedSlice(allocator);
   ```
