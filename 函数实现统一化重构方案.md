# 函数实现统一化重构方案

## 问题分析

### 当前状况

目前项目中存在严重的**代码重复问题**，同一个 PHP 函数在不同执行模式下有多个独立实现：

1. **VM 模式**：`src/runtime/builtin_*.zig`（如 `builtin_time.zig`, `builtin_random.zig`, `builtin_math.zig`）
2. **AOT 模式**：`src/aot/runtime_lib_template.zig`
3. **JIT 模式**：可能有独立的实现或调用 VM 实现
4. **FastVM 模式**：`src/runtime/fast_*.zig`

### 问题示例

以 `strlen` 函数为例：

**AOT 实现** (`src/aot/runtime_lib_template.zig`):
```zig
pub fn php_strlen(str: Value) !Value {
    if (!str.isString()) return Value.initInt(0);
    return Value.initInt(@intCast(str.asString().length));
}
```

**VM 实现** (通过 `builtin_registry` 调用):
```zig
// 在 VM 中通过函数指针调用
pub fn strlen(vm: *anyopaque, args: []const Value) !Value {
    // 类似的实现，但接口不同
}
```

### 核心问题

1. **代码重复**：同一逻辑实现多次，维护成本高
2. **接口不统一**：不同模式的函数签名不同
3. **功能不一致**：某些模式支持的函数，其他模式不支持
4. **测试困难**：需要为每个模式单独测试
5. **Bug 修复成本高**：修复一个 bug 需要在多处修改

---

## 重构方案

### 设计目标

1. **单一实现**：每个 PHP 函数只有一个核心实现
2. **接口统一**：通过适配器层适配不同模式的调用约定
3. **零成本抽象**：不引入运行时开销
4. **向后兼容**：不破坏现有代码

### 架构设计

```
┌─────────────────────────────────────────────────────────────┐
│                    调用层 (Call Layer)                       │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐   │
│  │   VM     │  │   JIT    │  │   AOT    │  │  FastVM  │   │
│  └────┬─────┘  └────┬─────┘  └────┬─────┘  └────┬─────┘   │
└───────┼─────────────┼─────────────┼─────────────┼──────────┘
        │             │             │             │
        ▼             ▼             ▼             ▼
┌─────────────────────────────────────────────────────────────┐
│                  适配器层 (Adapter Layer)                    │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐   │
│  │VM Adapter│  │JIT Adapter│ │AOT Adapter│ │Fast Adapter│  │
│  └────┬─────┘  └────┬─────┘  └────┬─────┘  └────┬─────┘   │
└───────┼─────────────┼─────────────┼─────────────┼──────────┘
        │             │             │             │
        └─────────────┴─────────────┴─────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│                核心实现层 (Core Implementation)              │
│                                                               │
│  src/runtime/core/                                           │
│  ├── string_functions.zig    (字符串函数核心实现)           │
│  ├── array_functions.zig     (数组函数核心实现)             │

│  ├── random_functions.zig    (随机数函数核心实现)           │
│  └── ...                                                     │
└─────────────────────────────────────────────────────────────┘
```

#### 1.2 定义统一接口

**`src/runtime/core/common.zig`**:
```zig
const std = @import("std");
const Allocator = std.mem.Allocator;

/// 核心函数的统一 Value 类型
/// 这是一个抽象接口，不同模式可以有不同的实现
pub const CoreValue = struct {
    // 使用 opaque 类型，由各模式自己实现
    data: *anyopaque,
    vtable: *const VTable,

    pub const VTable = struct {
        // 类型检查
        isNull: *const fn (*anyopaque) bool,
        isBool: *const fn (*anyopaque) bool,
        isInt: *const fn (*anyopaque) bool,
        isFloat: *const fn (*anyopaque) bool,
        isString: *const fn (*anyopaque) bool,
        isArray: *const fn (*anyopaque) bool,
        
        // 数据提取
        asBool: *const fn (*anyopaque) bool,
        asInt: *const fn (*anyopaque) i64,
        asFloat: *const fn (*anyopaque) f64,
        asString: *const fn (*anyopaque) []const u8,
        
        // 类型转换
        toBool: *const fn (*anyopaque) bool,
        toInt: *const fn (*anyopaque) i64,
        toFloat: *const fn (*anyopaque) f64,
        toString: *const fn (*anyopaque, Allocator) ![]const u8,
        
        // 引用计数
        retain: *const fn (*anyopaque) void,
        release: *const fn (*anyopaque, Allocator) void,
    };
    
    // 便捷方法
    pub fn isNull(self: CoreValue) bool {
        return self.vtable.isNull(self.data);
    }
    
    pub fn isString(self: CoreValue) bool {
        return self.vtable.isString(self.data);
    }
    
    pub fn asString(self: CoreValue) []const u8 {
        return self.vtable.asString(self.data);
    }
    
    // ... 其他方法
};

/// 核心函数的统一上下文
pub const CoreContext = struct {
    allocator: Allocator,
    // 可以添加其他共享资源
};
```

#### 1.3 实现核心字符串函数

**`src/runtime/core/string_functions.zig`**:
```zig
const std = @import("std");
const common = @import("common.zig");
const CoreValue = common.CoreValue;
const CoreContext = common.CoreContext;
const Allocator = std.mem.Allocator;

/// strlen - 获取字符串长度
/// 
/// 这是核心实现，不依赖任何特定的 Value 类型
/// 
/// @param ctx 上下文（包含 allocator 等）
/// @param str 字符串值
/// @return 字符串长度
pub fn strlen(ctx: *CoreContext, str: CoreValue) !i64 {
    _ = ctx;
    if (!str.isString()) return 0;
    const s = str.asString();
    return @intCast(s.len);
}

/// substr - 获取子字符串
/// 
/// @param ctx 上下文
/// @param str 源字符串
/// @param start 起始位置
/// @param length 长度（可选）
/// @return 子字符串（需要调用者管理内存）
pub fn substr(
    ctx: *CoreContext,
    str: CoreValue,
    start: i64,
    length: ?i64,
) ![]const u8 {
    if (!str.isString()) return "";
    
    const s = str.asString();
    const len = s.len;
    
    // 处理负数起始位置
    const start_idx: usize = blk: {
        if (start < 0) {
            const abs_start = @as(usize, @intCast(-start));
            break :blk if (abs_start > len) 0 else len - abs_start;
        } else {
            break :blk @intCast(@min(start, @as(i64, @intCast(len))));
        }
    };
    
    if (start_idx >= len) return "";
    
    // 处理长度参数
    const end_idx: usize = blk: {
        if (length) |length_val| {
            if (length_val >= 0) {
                break :blk @min(start_idx + @as(usize, @intCast(length_val)), len);
            } else {
                const abs_len = @as(usize, @intCast(-length_val));
                if (abs_len >= len - start_idx) return "";
                break :blk len - abs_len;
            }
        } else {
            break :blk len;
        }
    };
    
    if (start_idx >= end_idx) return "";
    
    // 分配新字符串
    const result = try ctx.allocator.alloc(u8, end_idx - start_idx);
    @memcpy(result, s[start_idx..end_idx]);
    return result;
}

/// strtoupper - 转换为大写
pub fn strtoupper(ctx: *CoreContext, str: CoreValue) ![]const u8 {
    if (!str.isString()) return "";
    
    const s = str.asString();
    const result = try ctx.allocator.alloc(u8, s.len);
    
    for (s, 0..) |c, i| {
        result[i] = std.ascii.toUpper(c);
    }
    
    return result;
}

/// strtolower - 转换为小写
pub fn strtolower(ctx: *CoreContext, str: CoreValue) ![]const u8 {
    if (!str.isString()) return "";
    
    const s = str.asString();
    const result = try ctx.allocator.alloc(u8, s.len);
    
    for (s, 0..) |c, i| {
        result[i] = std.ascii.toLower(c);
    }
    
    return result;
}

// ... 其他字符串函数
```

#### 1.4 实现核心时间函数

**`src/runtime/core/time_functions.zig`**:
```zig
const std = @import("std");
const common = @import("common.zig");
const CoreContext = common.CoreContext;

/// time - 返回当前Unix时间戳
pub fn time(ctx: *CoreContext) !i64 {
    _ = ctx;
    return std.time.timestamp();
}

/// microtime - 返回当前时间（带微秒）
/// 
/// @param ctx 上下文
/// @param get_as_float 是否返回浮点数格式
/// @return 如果 get_as_float 为 true，返回浮点数；否则返回格式化字符串
pub fn microtime(ctx: *CoreContext, get_as_float: bool) !union(enum) {
    float: f64,
    string: []const u8,
} {
    const now_ns = std.time.nanoTimestamp();
    const sec = @divTrunc(now_ns, std.time.ns_per_s);
    const usec = @divTrunc(@mod(now_ns, std.time.ns_per_s), std.time.ns_per_us);
    
    if (get_as_float) {
        const float_time = @as(f64, @floatFromInt(sec)) + 
                          @as(f64, @floatFromInt(usec)) / 1000000.0;
        return .{ .float = float_time };
    } else {
        const formatted = try std.fmt.allocPrint(
            ctx.allocator,
            "0.{d:0>6} {d}",
            .{ usec, sec }
        );
        return .{ .string = formatted };
    }
}
```

### 第二阶段：创建适配器层

#### 2.1 AOT 适配器

**`src/aot/core_adapter.zig`**:
```zig
const std = @import("std");
const core = @import("../runtime/core/mod.zig");
const runtime = @import("runtime_lib_template.zig");

/// 将 AOT 的 Value 转换为 CoreValue
fn aotValueToCoreValue(value: runtime.Value) core.CoreValue {
    return core.CoreValue{
        .data = @ptrCast(&value),
        .vtable = &aot_vtable,
    };
}

const aot_vtable = core.CoreValue.VTable{
    .isNull = aotIsNull,
    .isBool = aotIsBool,
    .isInt = aotIsInt,
    .isFloat = aotIsFloat,
    .isString = aotIsString,
    .isArray = aotIsArray,
    .asBool = aotAsBool,
    .asInt = aotAsInt,
    .asFloat = aotAsFloat,
    .asString = aotAsString,
    .toBool = aotToBool,
    .toInt = aotToInt,
    .toFloat = aotToFloat,
    .toString = aotToString,
    .retain = aotRetain,
    .release = aotRelease,
};

fn aotIsNull(data: *anyopaque) bool {
    const value: *runtime.Value = @ptrCast(@alignCast(data));
    return value.isNull();
}

fn aotIsString(data: *anyopaque) bool {
    const value: *runtime.Value = @ptrCast(@alignCast(data));
    return value.isString();
}

fn aotAsString(data: *anyopaque) []const u8 {
    const value: *runtime.Value = @ptrCast(@alignCast(data));
    const php_str = value.asString();
    return php_str.data;
}

// ... 其他 vtable 函数

/// AOT 版本的 strlen，调用核心实现
pub fn php_strlen(str: runtime.Value) !runtime.Value {
    var ctx = core.CoreContext{
        .allocator = runtime.runtime_allocator,
    };
    
    const core_value = aotValueToCoreValue(str);
    const length = try core.string_functions.strlen(&ctx, core_value);
    
    return runtime.Value.initInt(length);
}

/// AOT 版本的 substr，调用核心实现
pub fn php_substr(
    str: runtime.Value,
    start: runtime.Value,
    length: runtime.Value,
) !runtime.Value {
    var ctx = core.CoreContext{
        .allocator = runtime.runtime_allocator,
    };
    
    const core_str = aotValueToCoreValue(str);
    const start_int = start.toInt();
    const length_int = if (length.isNull()) null else length.toInt();
    
    const result_str = try core.string_functions.substr(
        &ctx,
        core_str,
        start_int,
        length_int,
    );
    
    // 将结果转换为 AOT Value
    const php_string = try runtime.PHPString.init(ctx.allocator, result_str);
    ctx.allocator.free(result_str); // 释放核心函数分配的内存
    
    return runtime.Value.initString(php_string);
}

// ... 其他适配函数
```

#### 2.2 VM 适配器

**`src/runtime/builtin_adapter.zig`**:

```zig
const std = @import("std");
const core = @import("core/mod.zig");
const types = @import("types.zig");
const Value = types.Value;
const VM = @import("vm.zig").VM;

/// 将 VM 的 Value 转换为 CoreValue
fn vmValueToCoreValue(value: Value) core.CoreValue {
    return core.CoreValue{
        .data = @ptrCast(@constCast(&value)),
        .vtable = &vm_vtable,
    };
}

const vm_vtable = core.CoreValue.VTable{
    // ... 类似 AOT 的实现
};

/// VM 版本的 strlen
pub fn strlen(vm: *anyopaque, args: []const Value) !Value {
    const vm_ptr = @as(*VM, @ptrCast(@alignCast(vm)));
    
    if (args.len != 1) return error.ArgumentCountMismatch;
    
    var ctx = core.CoreContext{
        .allocator = vm_ptr.allocator,
    };
    
    const core_value = vmValueToCoreValue(args[0]);
    const length = try core.string_functions.strlen(&ctx, core_value);
    
    return Value.initInt(length);
}
```

### 第三阶段：逐步迁移

#### 3.1 迁移优先级

**P0 - 高优先级**（功能简单，影响大）：
1. 字符串函数：strlen, substr, strpos, strtoupper, strtolower
2. 数学函数：abs, sqrt, round, floor, ceil, min, max
3. 类型检查：is_null, is_bool, is_int, is_float, is_string, is_array
4. 类型转换：intval, floatval, boolval, strval

**P1 - 中优先级**：
1. 时间函数：time, microtime, date
2. 数组函数：count, array_push, array_pop, in_array
3. 更多字符串函数：trim, ltrim, rtrim, str_replace

**P2 - 低优先级**：
1. 复杂字符串函数：explode, implode, str_split
2. 随机数函数：rand, mt_rand, random_int, random_bytes
3. 高级数组函数：array_slice, array_merge, array_keys, array_values

#### 3.2 迁移步骤（以 strlen 为例）

1. **实现核心函数**：
   ```bash
   # 在 src/runtime/core/string_functions.zig 中实现
   pub fn strlen(ctx: *CoreContext, str: CoreValue) !i64
   ```

2. **创建 AOT 适配器**：
   ```bash
   # 在 src/aot/core_adapter.zig 中
   pub fn php_strlen(str: runtime.Value) !runtime.Value
   ```

3. **更新 AOT runtime_lib_template.zig**：
   ```zig
   // 旧实现（删除）
   // pub fn php_strlen(str: Value) !Value { ... }
   
   // 新实现（调用适配器）
   pub const php_strlen = @import("core_adapter.zig").php_strlen;
   ```

4. **创建 VM 适配器**：
   ```bash
   # 在 src/runtime/builtin_adapter.zig 中
   pub fn strlen(vm: *anyopaque, args: []const Value) !Value
   ```

5. **更新 VM builtin_registry**：
   ```zig
   // 注册适配器函数
   const adapter = @import("builtin_adapter.zig");
   BuiltinFunction.init("strlen", .string, adapter.strlen, 1, 1, "...")
   ```

6. **测试验证**：
   ```bash
   # 运行所有模式的测试
   zig build test
   ./zig-out/bin/php-interpreter test_strlen.php
   ./zig-out/bin/php-interpreter --compile test_strlen.php && ./test_strlen
   ```

## 预期收益

### 1. 代码量减少

- **当前**：每个函数 × 4 个模式 = 4 份实现
- **重构后**：每个函数 = 1 份核心实现 + 4 个轻量适配器
- **预计减少**：60-70% 的重复代码

### 2. 维护成本降低

- **Bug 修复**：只需修改一处核心实现
- **功能增强**：所有模式自动受益
- **测试简化**：核心函数可以独立测试

### 3. 功能一致性

- 所有模式支持相同的函数集
- 行为完全一致
- 减少模式间的差异

### 4. 性能影响

- **编译时优化**：适配器层可以被内联，零运行时开销
- **AOT 模式**：完全内联，性能无损
- **VM 模式**：增加一层函数调用，但可以通过内联优化

## 风险与缓解

### 风险 1：性能回退
- **缓解**：通过内联和编译时优化消除抽象开销
- **验证**：运行性能基准测试

### 风险 2：接口不兼容
- **缓解**：保持向后兼容，逐步迁移
- **验证**：运行现有测试套件

### 风险 3：实施时间长
- **缓解**：分阶段实施，优先迁移高价值函数
- **验证**：每周评审进度

## 总结

这个重构方案将：

1. **消除代码重复**：从 4 份实现减少到 1 份核心实现
2. **统一接口**：通过适配器层适配不同模式
3. **提高可维护性**：Bug 修复和功能增强只需修改一处
4. **保证性能**：通过编译时优化实现零成本抽象
5. **向后兼容**：不破坏现有代码

这是一个长期投资，但会显著提高代码质量和开发效率。建议从 P0 高优先级函数开始，逐步迁移。
