## 4. 功能分类与参考方向

### 4.1 GC 与内存（AOT 当前为引用计数 + cycle 检测，升级时可参考）

| 文件 | 参考方向 |
|---|---|
| `complete_gc.zig` | 标记-清除-压缩 GC 堆管理；若 AOT 运行时由引用计数升级为追踪式 GC，可参考其 `CompleteGC` 堆压缩流程 |
| `gc_roots.zig` | 根集合管理（栈/全局/寄存器/跨代引用）；根扫描实现参考 |
| `cow.zig` | COW + 引用计数 + 原子操作线程安全；AOT 已有 COW（`make_ref` cow 标志），可对照其 `COWWrapper(T)` 泛型化与 `COWState` 三态设计 |

| `value_array.zig` | Value 类型版混合数组（packed/mixed 自动切换 + SIMD）；与 `packed_array` 对照，选型依据 Value 兼容性 |
