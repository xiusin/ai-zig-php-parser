## 一、本轮会话任务总览

### 1.1 任务背景

第六轮新增了 AOT 方法参数类型检查（`php_check_param_type` / `checkTypeMatch`），修复了 c043 TypeError 问题。但全量回归测试发现该修改引入了多个回归 BUG：

| 回归脚本 | 根因 |
|----------|------|
| test_047_readonly_props | `\DateTimeImmutable` 命名空间前缀不匹配 + `object` 伪类型不支持 |
| test_048_dnf_types | DNF 类型 `Cacheable&Loggable|null`（intersection/union）不支持 |
| t041_collection_class | `self` 类型提示未解析为实际类名 |
| c001_oop_magic_type_juggle | `mixed` 类型不隐含 nullable，null 被拒绝 |
| c012_command_undo_redo_macro | 匿名类 `implements Command` 接口未注册到 ClassMeta |

### 1.2 修复成果

| 编号 | 缺陷 | 修复方案 | 结果 |
|------|------|----------|------|
| REG-001 | 命名空间前缀 `\DateTimeImmutable` | `checkTypeMatch` 入口去掉前导 `\` | test_047 PASS |
| REG-002 | DNF intersection/union 类型 | 重构为分层架构 `checkUnionType`/`checkIntersectionType`/`checkSingleType` | test_048 PASS |
| REG-003 | `object` 伪类型 | `checkSingleType` 新增 object 接受任何对象 | test_047 PASS |
| REG-004 | `self`/`static`/`parent` 类型 | native_linker 生成检查代码时替换为实际类名 | t041 PASS |
| REG-005 | `mixed` 不接受 null | `php_check_param_type` 入口检查 `containsTypeComponent("mixed")` | c001 PASS |
| REG-006 | 匿名类 implements 接口丢失 | IR 生成器同时检查 `.named_type` 和 `.variable` 标签 | c012 PASS |

const iname: ?[]const u8 = switch (impl_node.tag) {

## 六、参数类型检查系统架构

### 6.1 当前支持的类型

| 类别 | 类型 | 说明 |
|------|------|------|
| 基本类型 | `int`, `float`, `string`, `bool`, `array` | 精确匹配 + 弱类型兼容（int→float, int→bool） |
| 伪类型 | `mixed`, `null`, `object`, `callable` | mixed 接受所有；object 接受任何对象；callable 接受 string/array/Closure/__invoke |
| 类类型 | 具体类名 | `isSubclassOf` + `implementsInterface` 检查继承链 |
| 特殊类型 | `Closure` | `isFunction()` 或 ClassMeta.name == "Closure" |
| self/static/parent | 方法所属类/父类 | native_linker 编译时替换为实际类名 |
| Union | `int\|string\|null` | `checkUnionType`: 匹配任一成员 |
| Intersection | `Cacheable&Loggable` | `checkIntersectionType`: 必须匹配所有成员 |
| DNF | `(Cacheable&Loggable)\|null` | union 成员可以是 intersection |

### 6.2 代码生成流程

```
PHP 源码: function merge(self $other): self
    ↓
IR 生成器: param_types = ["self"], param_nullable = [false]
    ↓
native_linker: 
  查找 TypeDef class_name → 找到 method → 
  ptype = "self" → resolved_ptype = class_name (如 "Collection")
  生成: try runtime.php_check_param_type("Collection::merge", 0, args[0], "Collection", false, "other");
    ↓
运行时:
  php_check_param_type → containsTypeComponent("mixed")? No →
  arg.isNull()? No →
  checkTypeMatch("Collection", got_type, arg) →
  checkSingleType("Collection", got_type, arg) →
  meta.isSubclassOf("Collection") || meta.implementsInterface("Collection")
```

### 6.3 未支持的特性

| 特性 | 说明 |
|------|------|
| `static` 后期静态绑定 | 当前 `static` = `self`（定义类名），PHP 语义中应为运行时类名 |
| 组合类型中的 self | `self|null` 中的 `self` 未被替换（走 nullable 标志路径） |
| callable 深度验证 | 仅检查值类型，未验证 string 是否为真实可调用函数名 |
| 全局函数参数类型检查 | 当前仅检查类方法，未检查全局函数 |

## 八、测试方法论

### 8.1 编译与测试命令

```bash
# 编译验证
timeout 120 zig build

# 单脚本 AOT 编译
timeout 60 zig-out/bin/php-interpreter --compile --no-debug-info <script.php>

# 单脚本对比测试
diff <(timeout 10 php <script.php> 2>/dev/null) <(timeout 10 ./aot_compile_<name> 2>/dev/null)

# 批量测试（fuzzy_scripts + fuzzy_scripts_73 + fuzzy_scripts_715/pass）
PASS=0; DIFF=0; FAIL=0; TOTAL=0; \
for f in fuzzy_scripts/pass/*.php fuzzy_scripts/fail_runtime/*.php fuzzy_scripts_73/*.php fuzzy_scripts_715/pass/*.php; do \
  TOTAL=$((TOTAL+1)); bn=$(basename "$f" .php); dir=$(dirname "$f"); \
  timeout 60 zig-out/bin/php-interpreter --compile --no-debug-info "$f" > /tmp/aot_compile_$$.log 2>&1; \
  if grep -q "Success" /tmp/aot_compile_$$.log; then \
    diff <(timeout 10 php "$f" 2>/dev/null) <(timeout 10 "$dir/aot_compile_$bn" 2>/dev/null) >/dev/null 2>&1 \
      && { PASS=$((PASS+1)); } || { DIFF=$((DIFF+1)); echo "DIFF: $bn"; }; \
  else FAIL=$((FAIL+1)); echo "FAIL: $bn"; fi; \
done; echo "=== TOTAL=$TOTAL PASS=$PASS DIFF=$DIFF FAIL=$FAIL ==="; rm -f /tmp/aot_compile_$$.log

# 清理编译产物
find . -name 'aot_compile_*' -type f -delete
rm -rf .zigphp_aot_build
```

### 8.2 可忽略差异规则

1. AOT 栈追踪行号/文件路径不一致 → 忽略
2. 浮点数末位精度差异 → 忽略
3. microtime/时间戳精度差异 → 忽略
4. 打印输出缩进不一致 → 忽略
5. Deprecated/Warning 警告差异 → 忽略（只要核心逻辑输出一致）

### 8.3 注意事项

1. **批量测试临时文件**: 多个并行测试不要共用 `/tmp/aot_compile.log`，使用 `$$`（PID）确保唯一
2. **编译产物命名**: 必须以 `aot_compile_{filename}` 前缀
3. **PHP 脚本保护**: 不可删除 `.php` 原始脚本
4. **测试超时**: 所有命令必须带 `timeout`，单脚本不超过 10 秒
5. **超大文件**: `native_linker.zig`(18,923行)、`runtime_lib_template.zig`(30,516行)、`ir_generator.zig`(9,517行) — 修改前必须 grep 搜索已有模式
