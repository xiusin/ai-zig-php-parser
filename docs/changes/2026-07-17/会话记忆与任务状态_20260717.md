## 六、测试方法论

### 6.1 编译与测试命令

```bash
# 编译验证
timeout 120 zig build

# 单脚本 AOT 编译
timeout 60 zig-out/bin/php-interpreter --compile --no-debug-info <script.php>

# 单脚本对比测试
diff <(timeout 10 php <script.php> 2>/dev/null) <(timeout 10 ./aot_compile_<name> 2>/dev/null)

# 批量测试
timeout 300 bash scripts/full_scan_aot.sh [目录]

# 清理编译产物
find . -name 'aot_compile_*' -type f -delete
rm -rf .zigphp_aot_build
```

### 6.2 可忽略差异规则

1. AOT 栈追踪行号/文件路径不一致 → 忽略
2. 浮点数末位精度差异 → 忽略
3. microtime/时间戳精度差异 → 忽略
4. 打印输出缩进不一致 → 忽略
5. Deprecated/Warning 警告差异 → 忽略（只要核心逻辑输出一致）

## 七、注意事项

1. **超大文件**: `native_linker.zig`(18,916行)、`runtime_lib_template.zig`(30,435行)、`ir_generator.zig`(9,513行) — 修改前必须 grep 搜索已有模式
2. **编译产物命名**: 必须以 `aot_compile_{filename}` 前缀
3. **PHP 脚本保护**: 不可删除 `.php` 原始脚本
4. **测试超时**: 所有命令必须带 `timeout`，单脚本不超过 10 秒
5. **GC 修改影响面**: 本轮 GC 保守策略影响所有 PHPArray/PHPObject/PHPClosure 释放路径
6. **mem2reg property_get 保护**: 影响 `$new = $this->data; usort($new, ...)` 模式，需全量回归验证
7. **参数类型检查**: 影响所有带类型声明的方法调用，可能对性能有影响
