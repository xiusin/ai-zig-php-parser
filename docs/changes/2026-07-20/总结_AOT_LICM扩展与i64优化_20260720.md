# AOT i64 快速路径优化与 LICM 扩展总结

**日期**: 2026-07-20  
**回归基线**: 114/115 PASS（c045 浮点精度忽略）

---

## 变更摘要

本轮完成 4 项任务，代码生成层 LICM 从仅支持 `load+call` 对扩展为支持单独 load 提升和纯算术运算提升，全量回归与基线一致。

| 任务 | 优先级 | 状态 | 核心变更 |
|------|--------|------|----------|
| IR 层 LICM 根因定位 | P4 | ✅ | 定位两个根因：状态机块编号破坏 + i64 类型分析破坏 |
| 代码生成层 LICM 单独 load 提升 | P3 | ✅ | 扩展 load 提升 + while 循环调用 + modified_addrs 修复 |
| 覆盖率报告脚本 | P3 | ✅ | 新增 `scripts/aot_coverage_report.sh` |
| 代码生成层 LICM 算术提升 | P1 | ✅ | 迭代不动点收集 `.add/.sub/.mul` + `loop_defined_regs` 修复 |

---

## 核心文件变更

| 文件 | 变更 |
|------|------|
| `src/aot/native_linker.zig` | `hoistLoopInvariantsAtCodegen`: 扩展单独 load 提升 + 算术提升 + modified_addrs 修复; `generateWhileLoopStructuredNew`: 添加 LICM 调用 |
| `src/aot/optimizer.zig` | LICM 配置保持 `false`（P4 根因未修复） |
| `scripts/aot_coverage_report.sh` | 新增覆盖率汇总脚本 |

---

## LICM 提升能力矩阵

| 指令类型 | 提升支持 | 备注 |
|----------|----------|------|
| `load(循环不变地址)` | ✅ | 单独提升或匹配 call 一起提升 |
| `call(纯函数, load 结果)` | ✅ | 白名单：array_sum/count/strlen/abs/max/min 等 |
| `.add(不变, 不变)` | ✅ | P1 新增，迭代不动点收集 |
| `.sub(不变, 不变)` | ✅ | P1 新增 |
| `.mul(不变, 不变)` | ✅ | P1 新增 |
| `.div/.mod` | ❌ | 未实现（需处理除零异常） |
| `.bit_and/.bit_or/.bit_shl` | ❌ | 未实现（P1 后续） |
| `call(非纯函数)` | ❌ | 有副作用的函数不可提升 |
