## 二、本会话完成的工作（按轮次）

### 第二十轮：releaseDeadOperands select UAF 修复与 bitwise copy 审查

**修复内容**：
- `releaseDeadOperands` 中 `.select` case：指针类型路径（ref_ptr result）下 `reg_X = reg_then` 或 `&reg_then` 是 bitwise copy（无 retain），但原代码释放 `then_value`/`else_value` → UAF。修复为检查 result 是否为 ref_ptr，若是则不释放 then/else。
- 完成 bitwise copy 指令系统审查：cast(释放✓)、move(不释放✓)、clone(不释放,保守安全)、box/unbox(不释放✓)、property_get(不释放object,保守安全)、phi(释放incoming✓,是唯一释放点)。

**根因**：指针类型 select 的 `reg_X = reg_then` 是 bitwise copy 无 retain，释放 reg_then 后 reg_X 悬垂。

**变更文件**：`src/aot/native_linker.zig` ~line 7399

### 第二十一轮：clone/property_get 操作数释放优化

**修复内容**：
- `.clone` case：`php_clone` 是深拷贝（创建全新对象，属性独立复制），`__clone` 在新对象上调用不引用原对象 → result 与 operand 完全独立 → 新增释放 operand。
- `.property_get` case：`getProperty` 内部 `_ = val.retain()`，`__get` 返回 retain 过的新值 → result 独立于 object → 从 `{}` 改为释放 object。
- 同时完成 method_call/parent_call/static_method_call/static_property_set/static_property_get 系列审查（全部正确，无需修改）。

**语义依据**：
- clone：`PHPObject.init` 创建新对象，数组 `cloneShallow`，对象 `retain`，`__clone` 在 `new_val` 上调用
- property_get：`getProperty` 的 `_ = val.retain()` + `__get` 返回 retain 过的值

**变更文件**：`src/aot/native_linker.zig` ~line 7360, ~line 7388

### 第二十二轮：releaseDeadOperands 去重性能优化 + emitPreGcCleanup 审查

**修复内容**：
- `releaseDeadOperands` 去重：`std.AutoHashMap` → 线性查找去重。`used_regs` 通常仅 1-4 个元素，HashMap 的分配+哈希+deinit 开销（~100ns/次）远大于线性查找（~2-16ns/次）。
- `emitPreGcCleanup` 审查：确认与 `releaseDeadOperands` 职责不同（GC 前强制释放存活引用 vs 每条指令后释放死亡操作数），不冗余不冲突，**无需调整**。

**变更文件**：`src/aot/native_linker.zig` ~line 7431

### 第二十三轮：异常路径 cleanup 完整性修复

**修复内容**：
1. **`cleanup_regs` 收集逻辑扩展**：从白名单（7种指令：new_object/const_string/concat/array_new/call/global_get/load）改为所有 `php_value`/`php_object` result。修复 method_call/static_method_call/property_get/clone/cast/box/array_get/interpolate 等指令在异常路径的内存泄漏。
2. **`generateCleanupCodeExcept` 跳过逻辑补齐**：补齐 `ref_ptr`/`this`/`ref_param_alloca` 跳过逻辑，与 `releaseDeadOperands`/`emitPreGcCleanup` 对齐，防止扩展 cleanup_regs 后这些寄存器被误释放导致 double free。

**根因**：
- `cleanup_regs` 仅收集 7 种指令的 result → 异常发生时其他堆值寄存器不被 cleanup → 内存泄漏
- `generateCleanupCodeExcept` 缺少 ref_ptr/this/ref_param_alloca 跳过 → 扩展后会 double free

**安全保障**：ref_ptr 跳过 + $this 跳过 + ref_param_alloca 跳过 + alloca 跳过 + catch_used 跳过 + regMayHeap 检查 + release 对 null/基本类型是 no-op

**变更文件**：`src/aot/native_linker.zig` ~line 3944, ~line 7510
