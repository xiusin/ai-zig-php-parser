# AOT-CODEGEN-012 类名族 CI（findClass 折形回落 + instanceof 规范名）_R128_2026-10-11_fbe6382a

## 1. 高层摘要（TL;DR）

1. **新立单 AOT-CODEGEN-012 并当轮关闭**：PHP 类名不区分大小写，AOT 运行期类表（`findClass`）精确匹配 ⇒ 跨大小写类使用全灭（new / instanceof / 静态调用 / class_exists / ::常量 6 形红）；`extends` 与 `::class`/`get_class` 拼写保真已绿（守卫）。
2. **修复（函数族 R-124/R-127 同款模式）**：①`findClass` 精确未命中回落 **CI 线性扫描**（运行期类查名唯一收敛点，grep 实测 **104 调用者** 一次性全族受益；命中路径零额外开销）；②`php_instanceof` 前置**规范名解析**（`findClass(name) → meta.name`）。
3. **落地轮两处自纠**：①重写 `php_instanceof` 时误删 Throwable 伪接口特判块 ⇒ 立即补回（Throwable 未注册，canonicalization 不覆盖）；②伪接口比较（Throwable/Stringable）仍是大小写敏感 ⇒ 改 `eqlIgnoreCase`（t3 探针 `instanceof stringable` 抓到）。
4. **验收**：门 M `red=0 green=8`（修复前注册 `red=5 green=3`）；Throwable/Stringable 双拼写探针全绿；影子 68 语料 md5 **68/68 一致**（类名跨大小写语料 0 处）；主回归 **Pass 67 / Skip 1**。
5. 工单 [AOT-CODEGEN-012](../../known-issues/AOT-CODEGEN-012-class-name-case-insensitive-lookup.md) 立单 + 门 M 建门 + 修复同轮完成。
