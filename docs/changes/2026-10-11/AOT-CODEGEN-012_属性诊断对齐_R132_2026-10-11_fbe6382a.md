## 1. 高层摘要（TL;DR）

1. **取证纠正**：R-131 登记「属性查名宽松方向」系**误读**——复测证实属性 get/set/isset/unset 的**值语义全部精确**（p1-p5：`->pr` 读静默 null 而非宽松读 5；isset/unset 精确；__get/__set 正确）。真实缺口 = **诊断面**（静默性缺口，与 CODEGEN-010 lexer 缺陷同款静默性）。
2. **R-132 落地（两处诊断对齐）**：①未定义属性读补 `PHP Warning: Undefined property: PC::$pr`（**与 PHP 逐字节一致**，含位置；__get 已接管路径不告警 ✓；@ 抑制由 emitWarning 自带 ✓）；②动态属性创建补 `PHP Deprecated: Creation of dynamic property PC::$pr is deprecated`（PHP 8.2 语义；stdClass 豁免；新增 `emitDeprecated` 助手）。
3. **验收**：门 M 扩至 **19 形 `red=0 green=19`**（+p1/p2 诊断对齐形）；p1 逐字节一致、p8 声明读无回归；`zig build test` 通过。
4. **登记新发现**：静态属性未声明 ⇒ 双方都报错但**形态不同**（PHP 可捕获 Error vs AOT 硬错误 `ERROR: Property SC.sp not found`——异常体系面，P2 登记）；dynamic property 的 `#[AllowDynamicProperties]` 豁免未实现（登记）。
5. 本轮源码仅 `runtime_lib_template.zig`（php_object_get 两处 miss 尾点 + emitDeprecated + php_object_set 动态属性 Deprecated）。
