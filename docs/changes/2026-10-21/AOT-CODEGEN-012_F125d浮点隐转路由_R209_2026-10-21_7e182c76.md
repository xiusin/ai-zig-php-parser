- 日期：2026-10-21
- 代次：`tpl 7e182c760e424393e77419f8e4daa555`（本轮唯一源改动；`nlk` 未动 `9410ae83…`）

## 1. 高层摘要（TL;DR）

`emitDeprecatedFloatToInt`（`str_repeat("a", 2.5)` 等隐式 float→int 的 E_DEPRECATED）此前只补了 `@` 抑制位，仍**绕过 `dispatchToUserHandler`** ⇒ `set_error_handler` 收不到这条诊断（PHP 会在 `@` 下也调用 handler）。本批按与 F-125-a/b 相同的顺序接线：**先路由 handler → 再查抑制 → 最后双流直写**，措辞与两行格式不动。

## 2. 影响范围

| 层面 | 影响 |
|---|---|
| 运行时诊断 | float→int Deprecated 现在会路由到用户 handler；返回 true 时不再标准打印；`@` 下 handler 仍被调用 |
| 发射器/优化器 | 无 |
| 生成码 | 无（模板不进 main.zig）⇒ 影子必须中性 |
| 语料 | 无 handler 时两行文本与顺序逐字不变（f3/f4 字节 SAME） |

## 3. 核心变更

| # | 位置 | 变更 |
|---|---|---|
| 1 | `emitDeprecatedFloatToInt` | 先算 `fstr`（原 `{d}`/非有限序列化口径不变）→ 组裸消息 `Implicit conversion from float {s} to int loses precision` → `dispatchToUserHandler(E_DEPRECATED, …)` → `isErrorSuppressed` → 原 stderr/stdout 直写 |

## 5. 详细变更分析

### 5.1 真值（PHP 8.5.8）
- handler 收到 **`CB|8192|Implicit conversion from float 2.5 to int loses precision`**；
- handler 返回 false ⇒ handler 后标准两行照打；
- `@` 下 handler 仍被调用，仅标准流被抑制。

### 5.2 涉及文件
- `src/aot/runtime_lib_template.zig`
