# Bug Report: 第一个 echo 三元运算符错误

## 问题描述

当文件的**第一个语句**是 `echo` + 三元运算符时，比较结果错误。

## 复现步骤

```php
<?php
echo 5 == 5 ? "eq" : "neq";  // 输出 "neq" ❌ 应该是 "eq"
?>
```

## Workaround

在第一个 echo 前添加任意语句：

```php
<?php
echo "";  // 添加这行
echo 5 == 5 ? "eq" : "neq";  // 现在输出 "eq" ✅
?>
```

## 测试结果

| 代码 | 预期 | 实际 | 状态 |
|------|------|------|------|
| `echo 5 == 5 ? "eq" : "neq";` (第一个语句) | eq | neq | ❌ |
| `echo ""; echo 5 == 5 ? "eq" : "neq";` | eq | eq | ✅ |
| `echo "Test: "; echo 5 == 5 ? "eq" : "neq";` | eq | eq | ✅ |
| `$r = 5 == 5 ? "eq" : "neq"; echo $r;` | eq | eq | ✅ |

## 可能原因

1. **栈初始化问题**：第一次执行时栈状态不正确
2. **标志位未重置**：某个全局标志位影响比较结果
3. **AST 解析问题**：第一个语句的 AST 节点解析错误

## 调试方向

1. 检查 VM 初始化代码
2. 检查栈操作的初始状态
3. 添加调试输出查看第一个 echo 的求值过程
4. 对比第一个和第二个 echo 的执行路径

## 优先级

**高** - 影响所有以 echo 三元运算符开头的脚本
