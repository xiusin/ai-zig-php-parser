### R-280：`readdir/rewinddir/closedir(null)` 的 last-opened 回退（F-178-b，已闭）
- 契约（PHP 8.5.8 实测）：三函数传 null ⇒ `Deprecated: <fn>(): Passing null is deprecated, instead the last opened directory stream should be provided`（**无** `parameter #1` 段）后按最后打开的目录流执行；无流 ⇒ 再加 `TypeError: No resource supplied`（可捕获，`@` 只压 Deprecated）；「最后打开」**只由 `opendir` 设定**，新 `opendir` 覆盖、`closedir(命中)` 清除；★该流**不随用户 `unset` 释放**（注册表自持引用）。
- 实现：`last_opened_dir: ?*Value.PHPResource`（`:5099`）＋ `setLastOpenedDir`（`:5101`）/`clearLastOpenedDir`（`:5111`）；`dirArgCheck` null 分支（`:5129`）；`php_opendir`（`:5184`）；`php_closedir`（`:5315`，清除必须是最后一步）；`initRuntime`（`:511`）/`deinitRuntime`（`:864`）。
