**根因分析**:
- 代码位置: `runtime_lib.zig:13084`
- 调用了不存在的方法 `arr.getByIndex()`
- PHPArray结构体缺少此方法定义

**修复建议**:
```zig
// 在 runtime_lib.zig 的 PHPArray 结构体中添加:
pub fn getByIndex(self: *const PHPArray, index: usize) ?Value {
    if (index >= self.items.len) return null;
    return self.items[index];
}
```
