**文件**: `fuzzy_scripts_715/fail_compile/c003_trait_interface_polymorphism.php`

**混搭维度**: Trait 组合 + 接口多态 + 抽象类 + 静态绑定 + 异常层级

**失败现象**:

    var reg_0: *runtime.Value = &reg_0_storage;
                                ^~~~~~~~~~~~~~
main.zig:167:33: note: pointer type child '*runtime_lib.Value' cannot cast into pointer type child 'runtime_lib.Value'

**根因分析**:

- AOT 编译器在处理 Trait 中的 `private static` 属性时，生成的 Zig 代码出现指针类型不匹配

**涉及代码片段**:
```php

    private static int $count = 0;
    public static function getCount(): int {
        return self::$count;
    }
}
abstract class Entity implements Comparable, StringRepresentable, Hashable {
    use CounterTrait;  // 此处触发编译错误
}
```

**BUG 分类**: Trait 静态属性代码生成

**优先级**: P2

### C019: VirtualFileSystem + PathResolve + DirTree + Metadata

**文件**: `fuzzy_scripts_715/fail_runtime/c019_virtual_filesystem_dirtree.php`

**混搭维度**: 虚拟文件系统 + 路径解析 + 目录树 + 遍历 + 元数据

<         [DIR] downloads
<         [DIR] projects
> AOT: [DIR] /

**根因分析**:

**涉及代码片段**:
```php

public function addChild(VirtualFile $child): void {
    $this->children[$child->getName()] = $child;
}
public function getChild(string $name): ?VirtualFile {
    return $this->children[$name] ?? null;
}
// mkdir 中的赋值
$current = $child;  // AOT 中为值复制
```

**BUG 分类**: 对象引用语义（值复制 vs 引用传递）

**优先级**: P1
