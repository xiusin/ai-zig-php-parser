# AOT编译器完整实现 - 需求文档

## 1. 概述

### 1.1 项目背景
当前AOT编译器已完成基础框架（Parser → AST → IR → Zig代码 → 可执行文件），但核心功能未实现：
- IR到Zig代码转换只生成注释
- 运行时库几乎为空
- 生成的可执行文件无法正确执行PHP代码

### 1.2 项目目标
实现完整的AOT编译器，使其能够将PHP代码编译为可独立运行的原生可执行文件，性能接近手写Zig代码。

### 1.3 成功标准
- `examples/hello.php` 能正确编译并输出预期结果
- 支持基本的PHP语言特性（变量、运算、控制流、函数）
- 生成的可执行文件性能优于解释器模式至少10倍
- 通过完整的测试套件（至少20个测试用例）

## 3. 功能需求

  ```zig
      null: void,

  };
  ```
